# 武器状态与生命周期研究结论

返回[项目入口](../../AGENTS.md)；当前实现见[架构](../architecture.md)，实体挂载见[模型研究](weapon-models.md)。

## 已得到的依据

早期自由飞行实验验证了普通导弹、QAAM、EML 的独立弹药、冷却阻断及连续切换。第二轮推进到任务 11，增加了 SASM/GPB 和 SASM/PLSL 两种组合的实际发射与反复切换。保存的[精简集成记录](../../evidence/integration/)属于旧实验原型，不能替代 0.1.7 实玩验收。

- 初始化兵装会重建并补满，不能直接当作换 SP。
- 冷却属于多个物理槽及发射轮换队列，而不是单个百分比。旧队列游标不能直接应用到新生成的实例。
- 未激活 SP 的冷却按游戏时间推进；暂停时间不应计入。
- 实验中的在途 QAAM/MSL 在切换后仍保持有效和运动，但这不证明所有持续制导、命中与伤害行为都正确。
- 手动原型接口中，两套 SP 补给和状态回滚可工作；真实自然返航闭环、检查点保存准确时机仍有覆盖边界。
- Easy 难度机炮为无限。有限机炮、干扰弹冷却和长时间使用不能从已有计数保存外推为全部验证。

## 本机原生布局

以下是当前 Steam 构建的历史定位与差分依据，**不是跨版本契约**：

| 记录 | 结论 |
|---|---|
| `PlayerPlane +0x11A8` | 玩家武器激活器，需绑定当前世界中的正确机体 |
| 激活器 `+0x260`，所属对象 `+0xF0` | 当前武器状态路径 |
| 状态 `+0x90 / +0x118` | 普通导弹/SP 计数，曾与 getter 及实际消耗核对 |
| 原生武器槽 `0x60` 字节 | 含变换、计时及尚未完整确认的不透明字段 |
| 槽 `+0x48 / +0x4C` | 装填时长/进度，曾做发射前后差分 |

更详细的原生函数体与接口记录位于[原生证据](../../evidence/native/)。它们来自旧进程，记录中的绝对地址不得重用。加壳 EXE 的部分磁盘代码无法正确反汇编，因此这些少量记录保留，不把无意义的原始资源副本或全部日志带入新目录。

## 后续优先事项

由用户正常菜单出击，确认最新原生准备页和 HUD 闪烁修复；随后补齐检查点、自然补给和特殊武器行为。双模型研究应先验证单机体的发射槽与实例生命周期，再决定是否扩展多机体。
