# 当前管理界面中文审核稿

打开[index.html](index.html)，不需要安装依赖或联网。旧的`management-design/`及其中批注原样保留，本稿按当前源码重新取值。

## 使用

1. 在“界面排版”中点击控件，在右侧修改名称、说明、显示形式、所属页面与分组；“页面分组”和“整体样式”可调整顺序、密度、导航、字号及宽度。
2. 在“全部弹窗与提示”中搜索或筛选，修改触发条件、拟改文字和意见。默认展示常用提示；底层异常在“错误映射”中，完整标签和消息片段在“全部”中。
3. 点击顶部“保存可编辑网页”，把下载的HTML交回。它同时保留布局和全部提示意见；也可导出JSON或文字意见。浏览器自动草稿不能替代导出文件。

## 当前基线和边界

- 四分页来自`management_panel.hpp`、`overlay.cpp`、`quick_mission_panel.hpp`及`version_updates_panel.hpp`，包含54个可编辑项目。属于结构示意，控件默认值为预览样例，不是读取当前个人配置；动态机体、购买、DLC和兵装列表不伪造。
- 608条清单包括532个游戏文字源词条、73个安装器提示及3个组合/动态通知模板。普通按钮标签单独分类，**不是608种独立弹窗**。267条底层错误映射保留断言/调用位置，具体错误经过统一翻译和故障处理后显示。
- 每条记录包含稳定编号、类别、触发条件、只读原文、拟改文字、意见、源文件行号和实际调用上下文。[提示清单.json](提示清单.json)是初始快照；你的导出HTML/JSON才包含后续修改。
- 游戏或第三方Mod提供的兵装描述、实际版本、机体名、错误原因等动态值无法穷举，使用占位符和组合模板；Lua路径及堆栈会被界面摘要处理，完整日志仍保留原始内容。
- 网页不操作游戏、安装、下载更新或保存正式设置。你修改的文案只存在于审核稿；确认中文后才按逐项意见修改正式中文资源并制作等义英文。
- 主界面保留标题、总开关、管理快捷键、语言、四分页、固定页脚与作者区域的位置。字号、宽度、换行及列表使用网页近似模拟，不冒充游戏像素截图。管理暂停与异常详情等条件提示的触发条件列在提示清单中。

生成入口为[src/research/build_management_review.py](../../../src/research/build_management_review.py)。它读取唯一文字源，复用旧稿编辑器而不覆盖旧稿；重新生成会刷新初始审核稿，因此必须先保存作者交回的设计文件。正式中文文件本轮未修改；没有编译或运行游戏测试。
