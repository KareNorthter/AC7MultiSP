# 有价值的方案决策

返回[项目入口](../AGENTS.md)。本页替代冗长的早期版本流水账；原理见[核心研究](research/core-findings.md)，证据目录见[索引](../evidence/README.md)。

| 问题 | 当前决定及原因 |
|---|---|
| 切换会补弹、重置冷却 | 重建前捕获独立状态，重建后映射装填队列；直接调用初始化接口无法满足需求 |
| 游戏运行后崩溃 | 旧栈出现 Lua 错误与回调注册链，不能断言武器重建是根因；周期和延迟调度统一到游戏线程，并保留明确错误 |
| F8 光标闪烁、回中 | 仅面板打开时管理自己的指针及相关输入限制，关闭时恢复；用户已确认光标问题修复 |
| 弹药耗尽后无法切换 | 切换逻辑使用即时计数，跳过耗尽 SP；不能继续展示停止同步前的缓存为实时值 |
| 独立任务 HUD 不融合 | 改用原生 UMG 列表，保留游戏字体、颜色、锚点和缩放 |
| 2K 下文字重叠 | 不按屏幕像素或箭头间距定位文字；使用真实原生列顺序与文字期望高度 |
| 切换时两行短暂互换 | SP1/SP2 显示控件固定身份，不再重排行身份；原生当前 SP 文本与可见两行分开 |
| 周期明显卡顿疑虑 | 去掉任务中的重复原生快照和全局扫描，内存交付 F8 状态；没有帧时间实测，不能宣称已确认旧模组为卡顿根因 |
| 原生准备页只有单 SP 流程 | 在原兵装页分阶段暂存双选，最后交回原生确认；多一次确认是明确取舍，实际跳转尚待用户验证 |
| 保留 F8 是否与原生融合冲突 | 用户明确要求保留为备用、调试入口；不在正常进入兵装页时自动弹出 |
| 双模型会在切换时瞬变 | 单纯叠加挂架会重叠且不解决发射来源；保留后续目标，暂不安装装饰性模型方案 |

旧版本二进制、重复包、失败测试临时文件已不作为开发依据；关键失败机制与尚未确认的边界仍在本页、研究文档及精选证据中保留。
