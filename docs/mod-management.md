# F8 管理界面与直接选择武器

2026-10-15 飞控兼容候选增加 `profiles.json` 的 `management_key`：默认 119（F8），允许 112–135（F1–F24），关闭游戏后修改，重启生效。本机为了避开 AC7MouseAim 的固定 F8，显式设为 117（F6）。界面帮助和武器改键排除项跟随此设置；保存其他设置时保留该字段。手柄 Back + Y 不变。本文其余 F8 表述是默认键位。该候选必须成套部署新 Lua/UI，不重编译武器核心。

切换替换机体与原版机体时，同一个机体编号可能对应不同武器。2026-10-15 新增机体批次将 CFA-44 恢复原版，因此备份并仅清除其 140 号旧方案；不会把替换版方案自动迁移到新增 PW-MKI 的 192 号。用户需在原生选装页重新确认。当前尚无通用于任意外部模组升级的方案身份自动迁移机制。

> 当前说明对应 [1.0.1](version-1.0.1.md)管理参数第 2 版。默认 Game Language，右下 HUD 与直接选武器固定启用，不提供未购买兵装试玩。多人时 F8、Back + Y、直接选择、暂停及鼠标接管全部禁用，返回明确单人入口后恢复。

本文描述 **AC7DualSP 1.0.1** 的当前管理规则，1.0.0 ZIP 没有更新。配置 schema 仍为 1，新增 management_revision=2。返回[项目入口](../AGENTS.md)，旧 ZIP 安装见 [TXT](AC7DualSP-安装说明.txt)，当前部署见[开发说明](development.md)。

用户已确认上一性能候选测试没有问题，具体记录见 [1.0.0](version-1.0.0.md)。这不等于每种手柄与每个参数组合都已覆盖。以下为当前规则，不再混列旧候选安装状态。

## 用户需求与交互

- F9 不再提供模组额外循环切换。原游戏的循环切换键继续使用。
- F8 仅管理模组功能、参数、按键与日志。删除兵装选择页、交换槽位、确认装备按钮，以及允许旧界面提交兵装配置的控制器分支；原生出击与返航补给页负责 SP1/SP2 选择。
- F8 固定显示“语言选择/Select Language”，可选 Game Language、中文 / Chinese、English。默认跟随游戏，切换可预览，点击保存后记住；日志和具体错误保持记录原文。
- 直接选择功能固定启用，无总开关。键盘默认 1 / 2 / 3，支持点击改键；手柄固定十字键左 / 上 / 右，无改键选项。
- 中央常驻简称有独立开关。关闭时移除常驻控件并还原原生提示面板，由游戏继续显示短暂武器切换提示；不把原提示改为另一种模组计时提示。
- 右下列表及就绪名称变淡始终启用，不提供开关，仍服从原生 HUD 全局显隐和多人禁用。
- 双 SP 配弹滑块为 50% 至 100%，每 5% 一档，包含端点共 11 档。移除未购买兵装试玩入口及其购买检查放行逻辑。
- 点击保存后显示等待状态；收到游戏线程确认才显示保存成功。关闭会丢弃未保存修改，不会取消已经提交的保存请求。

## 直接选择规则

| 目标 | 默认键盘键 | 固定手柄键 |
|---|---|---|
| MSL | 1 | 十字键左 |
| SP1 | 2 | 十字键上 |
| SP2 | 3 | 十字键右 |

键盘支持单个字母、数字、常用编辑/方向键、功能键及小键盘键，不支持组合键。F8 保留为管理入口，Esc 用于取消改键；三个选择键不能重复。大键盘数字与小键盘数字分开保存。普通 F9 没有预设模组功能；若用户主动将它绑定到某个目标，则仅执行那个直接选择动作。与原生键位冲突由用户自行修改，不改变原生映射，也不屏蔽原生对应动作。

键盘只处理首次按下，手柄使用方向按下边沿；按住不重建，重复选择当前武器也不重建。手柄多个选择方向同时按下不猜测目标，日志记录原因。沿用现有 XInput 0 号手柄接入；其他设备映射和控制器型号仍需用户验证。

装填中的武器允许选择；SP2 未配置或目标 SP 耗尽时保持当前选择，并在日志和管理界面提供原因。MSL 始终是独立目标。任务未配置、暂停、F8 打开、补给、武器输入不可用或切换事务尚未完成时不执行直接选择，也不保存延后执行请求。

直接选择复用统一的逻辑选择事务：必要时重建目标 SP 并恢复弹药/冷却，再完成原生类别切换，最后统一更新两处 HUD。渲染线程仅提交目标，不接触 UE 对象或武器内存；游戏线程核对场景和最终选择。

## 参数和旧配置

沿用 `profiles.json` 的 schema 1 与既有按机体保存的兵装方案；新增字段如下：

| 字段 | 默认或行为 |
|---|---|
| `language` | 默认 `auto`（Game Language）；可选 `zh`、`en` |
| `management_revision` | `2`，标记本次一次性参数迁移 |
| `keyboard_keys` | `[49,50,51]`，依次为三个目标的 Windows 单键编号 |
| `central_hint` | 默认启用；关闭恢复原生短暂提示 |
| `ammo_ratio` | 0.5 至 1，每 0.05 一档；新配置默认 0.5 |

首次迁移按用户要求设 language=auto，移除 hud、direct_select、ignore_unlocks、旧 hud_scale 字段，将旧全局配弹比例取最近 5% 档并至少为 50%；日志明确记录前后值，原文件保留到 profiles.previous.json，安装器另有完整备份。后续启动不重置手动语言。旧 native_loadout 关闭选项仍移除；profiles 中机体方案、键位、中央简称设置保持不变。缺少合法已确认方案时明确报错，不自动配置单 SP。

中央简称开关与键位保存成功后生效。配弹比例用于下一次新打开的原生准备/补给草稿；保存设置不修改当前任务弹药、已有草稿或检查点方案。单 SP 仍保留完整载弹量。

错误不会用默认键位静默替换。设置完整验证且写盘成功后才替换当前配置；验证或保存失败显式显示，并保留当前有效运行设置。模块已经报告接入或采样错误时，不通过开关静默重试；按日志修复后重新进入任务或重启。

## 日志与开销

F8 的日志页分别显示 `mod.log` 和 `native.log`，每份最多读取最后 64 KiB，仅打开日志页或点击刷新时读取。读取失败明确报告，不持续读取整个文件，也不读取存档。

键盘复用现有窗口消息与动作队列；手柄在允许直接选择时最多每 20 ms 一次，其他单人场景保留管理快捷键的 100 ms 采样，多人时停用。仅实际按键会产生操作请求，不增加正常飞行的全局对象扫描。

## 协议边界

控制器与 UI 使用 management_protocol=2；设置请求也携带协议号，拒绝旧 UI 提交已移除的参数。当前 UI 还提供只读准备页键盘导航。缺少 dualsp_management_supported 或 dualsp_preparation_navigation 时安装器明确拒绝。不要单独替换 Lua 或 DLL。

历史上管理页改造曾遗漏 refreshState，导致编译失败；已恢复完整状态同步。旧 F9 轮换、F8 兵装编辑及额外确认页均已退役，不再作为当前入口。历史研究见[索引](history-1.0.0.md)。
