# 管理、键位与配置

对应 1.1.0。用户操作见[安装说明](AC7DualSP-安装说明.txt)，验证范围见[当前状态](status.md)。

## 管理和直接选择

默认 F6，手柄 Back+Y。已有显式管理键保留，旧 F8 不被强制改写；默认语言跟随游戏，可选中文/英文。
普通“保存设置”修改语言、中央简称开关和四个直接选择键，不触发任务内换装。

| 目标 | 键盘 | 手柄 |
|---|---|---|
| 普通导弹 MSL | 1 | 十字键左 |
| SP1 | 2 | 十字键上 |
| SP2 | 3 | 十字键右 |
| SP3 | 4 | 十字键下 |

键位使用单键，四键互不重复，也不能与管理键冲突。只响应按下边沿，不因按住或重复选择当前武器持续重建。
原切换键继续循环，跳过未选和耗尽的 SP；装填中仍可选择。任务未准备好、暂停、补给或切换事务未完成时，不保存延后执行的选择请求。
渲染线程只排队，游戏线程负责最终场景和武器校验。

界面支持 Tab/Shift+Tab、方向键、Enter、空格与 Ctrl+Tab/Ctrl+Shift+Tab；Esc 先退出下拉框，再关闭面板。
F6 在任务中按所有权取得暂停，关闭只释放自己取得的部分；原有暂停保留。交接失败明确显示错误，不通过强行清零掩盖。

## 任务内调试

“应用 SP 方案并补满”是独立动作，只作用于当前机体已购买的 1 至 3 种 SP。
成功后选回 MSL，保留普通导弹弹药/冷却、机炮、干扰弹、个人方案和已有检查点；后续新检查点可包含调试方案。
不换飞机、不修复机体、不代替原生出击或补给。等待已发射武器结束；当前活动登记为空也不等于已证明追踪了所有旧弹体。
不可用原因与失败必须可见，不能静默转成其他选装流程。

## 配置契约

`ue4ss/Mods/DualSP/profiles.json` 不入 Git，通常不需要用户手改。

| 字段 | 当前含义 |
|---|---|
| schema | 2 |
| management_revision / management_protocol | 3；前者是配置迁移标记，后者是 UI 通信协议 |
| keyboard_keys | 默认 [49,50,51,52]，MSL/SP1/SP2/SP3 |
| management_key | 缺省 117（F6），允许 F1–F24，保留显式旧值 |
| language | auto / zh / en |
| central_hint | 中央简称开关，当前 1.1.0 仍可关闭 |
| profiles | 按机体保存 a/b/c 三槽方案，未使用槽为 -1 |

配弹按已装部件后的完整载量除以实际 SP 数并向下取整；正载量至少一发，零载量仍零。ammo_ratio 滑块已经移除。

schema 1 首次迁移前备份到 profiles.before-three-sp.json：旧第三槽补空，新增数字 4 直接键，迁移到 schema 2/管理参数 3。旧直接键占用 4 时明确拒绝，先在旧版本调整；已有迁移备份冲突也不覆盖。
设置完整校验和写盘成功后才切换有效配置；错误不自动替换成默认值。不要混装旧协议 UI、Lua 和核心。
