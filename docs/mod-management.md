# F8 管理界面与直接选择武器

本文描述 **AC7DualSP 1.0.0**，管理窗口标题已统一；内部配置 schema 与旧版兼容。返回[项目入口](../AGENTS.md)，新手安装见 [TXT](AC7DualSP-安装说明.txt)，开发部署见[开发说明](development.md)。

用户已确认上一性能候选测试没有问题，具体记录见 [1.0.0](version-1.0.0.md)。这不等于每种手柄与每个参数组合都已覆盖。以下为当前规则，不再混列旧候选安装状态。

## 用户需求与交互

- F9 不再提供模组额外循环切换。原游戏的循环切换键继续使用。
- F8 仅管理模组功能、参数、按键与日志。删除兵装选择页、交换槽位、确认装备按钮，以及允许旧界面提交兵装配置的控制器分支；原生出击与返航补给页负责 SP1/SP2 选择。
- F8 提供中文、英文选项。切换语言可预览，点击保存后记住。标题、页面、开关、说明和按键名称按语言显示；日志和具体错误保持记录原文。
- 直接选择功能有总开关，键盘默认 1 / 2 / 3，支持在界面点击改键；手柄固定十字键左 / 上 / 右，无改键选项。
- 中央常驻简称有独立开关。关闭时移除常驻控件并还原原生提示面板，由游戏继续显示短暂武器切换提示；不把原提示改为另一种模组计时提示。
- 右下列表及就绪名称变淡沿用独立 HUD 开关；关闭中央简称不关闭右下功能，关闭右下功能不关闭中央简称。
- 保留双 SP 配弹比例与未购买兵装试玩参数，不提供兵装配置的第二套操作。
- 点击保存后显示等待状态；收到游戏线程确认才显示保存成功。关闭会丢弃未保存修改，不会取消已经提交的保存请求。

## 直接选择规则

| 目标 | 默认键盘键 | 固定手柄键 |
|---|---|---|
| MSL | 1 | 十字键左 |
| SP1 | 2 | 十字键上 |
| SP2 | 3 | 十字键右 |

键盘支持单个字母、数字、常用编辑/方向键、功能键及小键盘键，不支持组合键。F8 保留为管理入口，Esc 用于取消改键；三个选择键不能重复。大键盘数字与小键盘数字分开保存。普通 F9 没有预设模组功能；若用户主动将它绑定到某个目标，则仅执行那个直接选择动作。与原生键位冲突由用户自行修改，不改变原生映射，也不屏蔽原生对应动作。

键盘只处理首次按下，手柄使用方向按下边沿；按住不重建，重复选择当前武器也不重建。手柄多个选择方向同时按下不猜测目标，日志记录原因。沿用现有 XInput 0 号手柄接入；其他设备映射和控制器型号仍需用户验证。

装填中的武器允许选择；SP2 未配置或目标 SP 耗尽时保持当前选择，并在日志和管理界面提供原因。MSL 始终是独立目标。任务未配置、暂停、F8 打开、补给、武器输入不可用或切换事务尚未完成时不执行直接选择，也不保存延后执行请求。

直接选择复用统一的逻辑选择事务：必要时重建目标 SP 并恢复弹药/冷却，再完成原生类别切换，最后统一更新两处 HUD。渲染线程仅提交目标，不接触 UE 对象或武器内存；游戏线程核对场景和最终选择。

## 参数和旧配置

沿用 `profiles.json` 的 schema 1 与既有按机体保存的兵装方案；新增字段如下：

| 字段 | 默认或行为 |
|---|---|
| `language` | `zh`；可选 `en` |
| `direct_select` | 默认启用，统一控制键盘和手柄直接选择 |
| `keyboard_keys` | `[49,50,51]`，依次为三个目标的 Windows 单键编号 |
| `central_hint` | 默认启用；关闭恢复原生短暂提示 |
| `hud` | 沿用原右下列表开关 |
| `ammo_ratio` | 可设置 0.1 至 1；旧配置没有此字段时，先沿用原机体的比例 |
| `ignore_unlocks` | 沿用原试玩参数，不修改存档购买记录 |

旧 `native_loadout` 关闭选项不再生效，也不再保存；用户最新要求规定原生双选为唯一入口。旧 `profiles` 不清空、不换成默认兵装。缺少合法已确认方案时明确报错，要求返回机库原生确认，不自动弹出 F8 选兵装，也不自动配置单 SP。

开关与键位保存成功后用于后续操作，中央提示在下次 HUD 更新时恢复/接入。配弹比例变为全局管理参数，用于下一次新打开的原生准备/补给草稿；保存设置不修改当前任务弹药、已有草稿或检查点方案。单 SP 仍保留完整载弹量。首次保存管理设置前保留旧机体各自的配弹比例，保存后使用所选全局比例。

错误不会用默认键位静默替换。设置完整验证且写盘成功后才替换当前配置；验证或保存失败显式显示，并保留当前有效运行设置。模块已经报告接入或采样错误时，不通过开关静默重试；按日志修复后重新进入任务或重启。

## 日志与开销

F8 的日志页分别显示 `mod.log` 和 `native.log`，每份最多读取最后 64 KiB，仅打开日志页或点击刷新时读取。读取失败明确报告，不持续读取整个文件，也不读取存档。

键盘复用现有窗口消息与动作队列；手柄复用原有 XInput 读取，启用直接选择时最多每 20 ms 一次，关闭时保持原管理快捷键的 100 ms 采样。仅实际按键会产生操作请求，正常飞行不增加原生对象扫描、周期武器快照或新的绘制层。预期开销很小，尚未测量帧时间。

## 协议边界

控制器与 UI 双向核对管理协议；当前 UI 还提供只读准备页键盘导航。缺少 dualsp_management_supported 或 dualsp_preparation_navigation 时安装器明确拒绝。不要单独替换 Lua 或 DLL 形成新旧混装。

历史上管理页改造曾遗漏 refreshState，导致编译失败；已恢复完整状态同步。旧 F9 轮换、F8 兵装编辑及额外确认页均已退役，不再作为当前入口。历史研究见[索引](history-1.0.0.md)。
