AC7MultiSP 安装说明

本说明适用于通用ZIP及配套EXE安装程序。vortex安装和exe安装请任选一种，更新和卸载也沿用同一种方式，不要混用。
不支持CreeperUX启动器安装（因为本mod同时含有ue4ss组件和pak文件，CreeperUX不拷贝pak文件）

一、EXE安装
1. 运行AC7MultiSP_Installer.exe，选择“直接安装”。
2. 确认游戏文件夹；未自动找到时，选择含Ace7Game.exe的文件夹。
3. 点击“安装”或“更新”，等待完成。


二、Vortex安装
1. 在Vortex中管理《皇牌空战7》，启用对应的游戏支持扩展。并安装AC7专用UE4SS：https://www.nexusmods.com/acecombat7skiesunknown/mods/2474
2. 从Nexus通过“Mod Manager Download”下载通用ZIP，或用“Install From File”导入已下载的ZIP。
3. 安装后确认Mod类型为“Engine Injector”；如显示为其他类型，先改为此类型。
4. 启用Mod并部署，再通过Steam启动游戏。

三、手动安装
1. 安装AC7专用UE4SS。
2. 将ZIP中的ue4ss和Game两个文件夹合并复制到游戏文件夹。不要复制ZIP外层文件夹，其他说明及管理文件无需复制。

四、来源核对（适用于提供作者签名材料的版本）
本Mod完全免费。签名版安装器会在安装、卸载、恢复或导出前核对内置发行文件；核对失败会停止操作，请保留文件并从作者原发布页核对来源。
如作者提供AC7MultiSP-release.json及AC7MultiSP-release.sig.json，可将它们与同版EXE、通用ZIP原文件放在同一文件夹，用已确认来源的签名版安装器运行：
AC7MultiSP_Installer.exe --verify-release "待核对的文件夹"
此入口只读取清单列明的发行文件，不安装或修改待核对文件。Vortex不会自动执行作者签名核验，手动安装也请先核对来源。部分旧版本没有作者签名，继续以原发布记录为准。
签名一致表示文件由对应作者密钥批准，不能证明下载或销售渠道获得授权，也不能阻止原包被转售。
