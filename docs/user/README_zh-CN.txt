本文说明正式2.24.1功能。更新检查及双下载入口仍需后续实机验收。

让一架飞机携带多种特殊兵装：单人战役/自由任务中可选择1至3种SP，分别保留库存、装填、HUD和切换。多人模式停用。适用原生Steam build9855922、Windows 10/11 x64；其他游戏版本和原生VR玩法不在兼容保证范围内。

安装与配置参考见安装说明.txt。安装交付方式将另行整理。

基本操作
• 新配置默认：模组、任务模型、机库模型及十字键直选开启；机炮齐射开启，中心白点关闭；兵装文本切换后显示1秒；手柄/键盘注视及视角保持分别关闭；NEXT使用原生排序。界面支持中文/英文，语言默认自动。有效配置19保留个人选择。
• 各SP独立保留库存和装填。单SP使用完整弹量，双SP默认各50%、三SP默认各33%，可在基础功能页调整；原生无限库存显示---。
• 面板设置修改后点保存；关闭会丢弃未保存更改。语言和按键保存后应用，总开关等待安全菜单，弹药比例等待下一次配弹。
• 原生准备页依次选择SP1/SP2/SP3，后两项可选NO WEAPON；未购买的SP不进入普通选装列表。左下显示光标兵装的原生长说明并跟随游戏语言。
• 键盘默认1/2/3/4选择普通导弹/SP1/SP2/SP3。十字键左/上/右/下对应同样顺序，可单独关闭；X保留原生轮切。键鼠单键允许同时按修饰键，明确设置的完整组合快捷键优先。
• F6或Back+Y打开管理，任务中打开会暂停，关闭只归还本面板拥有的暂停。基础功能、视角、调试、版本和更新四页；日志在调试末尾展开。
• 任务/机库模型开关相互独立，只控制外观，不影响多SP选择、弹药和注视。任务模型快捷键默认未绑定，可通过配置文件指定；关闭机库模型可恢复原生展示以改善机库低帧。
• 轮切调试SP组合默认无快捷键；Ctrl+Alt+F6切视角保持；Ctrl+Alt+F5切机炮齐射，携带MGP/HGP/PLSL吊舱时，按住机炮发射键会联动该武器齐射；同方案多种合格炮类暂不联动。
• 在管理视角页切NEXT原生/VR模式，不设快捷键；VR表示视野中心优先。与鼠标飞控并用时，请关闭其F2 HMD目标功能以免争抢目标。白点、注视和视角保持可分别设置。
• 视角保持默认关闭。L3/R3镜头操作固定保留：L3单独按下并松开回正、结束当前锁定注视；R3短按切普通视角、长按0.3秒切视角保持并保存，松开不再换视角。双摇杆只干扰弹。回中键默认鼠标中键，灵敏度默认100%，可调5%～200%；角度自动回正及滑条已移除。
• 手柄/键盘锁定注视各自默认关闭；启用对应来源后Y长按0.2秒开始/结束，短按仍切目标并随新目标注视。键盘使用游戏实际绑定的原生注视键，按一下开始、再按一下结束；不再提供单独的注视功能启闭自定义键。暂停、失焦、管理、目标消失、特殊镜头或离场会结束注视。
• 调试页可临时重配SP、补满SP弹药。无限弹药与快速装填默认关闭，仅本次游戏会话生效，只作用于本Mod管理的SP；无限不自动补满，快速装填将合格SP等待缩短至最多1秒，排除炮类及持续效果类。
• 普通保存不补充当前弹药；调试“换机并重开任务”会重新开始整关。支持检索三SP目录完整的Mod机体，使用当前真实引用和涂装SP，不授予DLC/购买许可。
• 第13关113使用任务指定SP，离开恢复；同地图自由飞行213不受影响。第12/14关保留多SP。
• “版本和更新”页显示作者、邮箱karenorthterofchina@gmail.com、测试反馈QQ群1072924682及授权信息。首次主菜单后自动检查一次，失败可点“手动检测更新”重试；检查中不能重复请求。仅任务外提醒新版，点蓝奏云或R2入口后由Windows默认浏览器打开，退出游戏后按下载包说明安装。准备中清单显示“更新信息尚未发布”，检查失败不影响兵装功能。
• 短暂通知显示在屏幕上方居中，带ACMultiSP: 前缀，同帧错开排列；普通通知约1秒，警告、错误及重要信息约3秒。无模型方案时提示“此机体暂无多SP模型方案适配”，仍可使用多SP兵装。

已知边界
• 首次载入、选装页面、结算箭头和部分机型仍可能卡顿；F-2A模型性能及其他偶发退出继续按独立现场处理。
• F-22准备页已定位的字段名生命周期问题已在本Mod路径规避，不代表通用加载器或所有第三方Mod已修复。
• F-14IA现有隐藏隔离保留，其原生资源依赖崩溃未列为已修复。
• 已有验收不扩大为全机全组合、所有Mod兼容或固定帧率保证。机体Mod不适配多SP模型时可关闭模型外观，具体兼容行为仍取决于Mod本身。
• FALKEN激光/尾迹期间切换请求忽略，结束后重按；PLSL/MGP齐射切槽可能有间隙。
