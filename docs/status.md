## 限制与下一步

- UAV/ECM 只允许单挂；TLS 切到另一 SP 仍结束。F-15E TLS→MSL 已验证可自然结束。
- 机库和演出实例多挂预览未适配；第三方兼容只按历史具体批次理解。
- 优先补充代表性的原生补给单挂↔多挂、检查点、换机再出击及长时稳定性证据。调试换装不能替代原生流程。
- 扩机型优先研究 F-22A 共用弹仓，再考虑活动炮体与阵列；这是待办，不是本次操作授权。
- 先评估待合入 UI 分支，避免同一问题重复开发；不整枝覆盖当前主线。
- 构建依赖摘要不完整、正式流程仍使用研究入口，列入下一轮工程整理；本轮不改工具代码。
