# 版本更新说明

本日志整理至正式 **2.24.1**，资料基线 `39141fd`；项目当前状态统一见[项目入口](../../README.md)。本文是版本历史唯一维护正文；当前功能、默认值及边界见[中文说明](../user/README_zh-CN.txt)或[英文说明](../user/README_en.txt)，安装见[安装说明](../user/安装说明.txt)。历史功能可能已调整或撤回，不能直接当作当前操作说明。

“正式”表示有明确主线定名或发布依据；“候选/研究”保留当时编号，不代表发布过同号正式包。早期未逐版核实的条目只记已知变化，不补造发布日期或验收。尤其 **2.25.x、2.26.0是正式2.22.0之前的研究编号**，并非比2.24.1更晚的正式版本；旧2.23.x、2.24.0研究编号也须按来源区分。

## 最近正式版本

### 2.24.1（正式）

相对2.23.1：

- 新增双语第四页“版本和更新”，显示作者、邮箱 `karenorthterofchina@gmail.com`、测试反馈QQ群 `1072924682` 和授权信息；提供蓝奏云/R2浏览器下载入口。作者及贡献者名字保留原文。
