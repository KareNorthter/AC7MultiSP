# 玩家文档维护与复用

本页供开发者和AI使用。玩家只需阅读[四个主题的正文](../README.md#玩家文档先审阅这四份)。当前中文重写稿已获用户基本认可，仍可人工修改；英文对应稿待补齐，授权条款按用户要求留待补充；没有改EXE、ZIP或F6程序。

## 唯一正文与展示位置

| 正文路径 | EXE安装程序 | ZIP内文档 | F6文档展示 |
|---|---|---|---|
| docs/user/功能说明.txt | 功能说明入口 | 独立文件 | 不展示 |

上表列出当前中文源文件；四个主题均必须补齐英文对应稿，并在本表登记路径。每个主题每种语言只有一个来源，译文不按EXE、ZIP或F6分别维护。英文文件尚未创建，不能用旧英文README冒充已同步。

F6这里限定的是文档展示，不删除管理设置、状态提示或其他功能。版本号来自产品元数据，不在正文多处手工维护。正文为UTF-8纯文本，标题、段落和项目列表可直接阅读；UI可以调整排版，不另写一套内容。其他用户交互的双语要求见[开发规范](workflow.md#用户交互与双语)。

## 维护规则

- 用户直接修改这四份文件即为正文修订，后续AI先读最新差异，不用旧聊天或内置文案覆盖人工修改。
- 功能说明写玩家能做什么、如何操作、适配机体和确有影响的限制；源码位置、检查数字、性能计量和交接状态放工程文档。
- 安装说明按实际提供的三种方式写步骤；未正式提供的方式保留简短预览标记。以后安装方式改变只改这份正文。
- 更新日志按大功能阶段归并，只写用户可见变化，不逐补丁追加，不展示内部研究编号、提交、配置号或测量过程。当前档案中的2.25/2.26研究号不写入玩家日志。
- 作者条款不能代填。“待作者补充”是用户确认的审核项，不解释为允许或禁止转载。第三方许可证与原始致谢保留，不能用新的短文替代许可证全文。
- 不再维护独立release.txt、长篇中英README或安装器专属版本说明。旧英文全文已从日常树移出；必须以当前四份中文逐份等义翻译，后续中英文同步修订，不沿用旧英文作为现行正文。

## 后续接入边界

1. 补齐中英文并完成正文审核后，EXE、ZIP、F6统一从对应语言文件读取或在构建时嵌入；生成的副本不手工修改。
2. F6只嵌入更新日志和作者与授权。作者页头需要单独布局时，从同份正文提取，不再独立保存作者名和邮箱文字。
3. 若发布页或界面只显示部分更新，按正文的版本分节截取，不能再手写另一份摘要。
4. 修改代码与打包流程时，再适配文档路径和源码冻结规则。本轮只准备内容和索引，不宣称现有安装器、ZIP或F6已同步。
