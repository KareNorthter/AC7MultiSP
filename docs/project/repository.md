# GitHub仓库与本机材料

目标仓库：[KareNorthter/AC7MultiSP](https://github.com/KareNorthter/AC7MultiSP)，**私有**。它保存正式源码、工程文档和研究恢复锚。当前中文玩家说明、英文待补齐及授权待补充的状态仍见[项目入口](../../README.md)；本轮不接入新的界面文案或交付流程。

## 上传范围

- main是唯一正式分支，保留其提交历史；现有正式版本标签和明确登记的研究/归档标签一并保存。
- 尚待甄别的本地研究分支以`archive/github-initial-20261023/原分支后缀`标签保存当次已提交tip。GitHub不把它们列为并行正式分支；继续研究仍从当前main取精确差异。逐项映射见[本机整理清单](../../evidence/local-assets-20261023.json)。
- 本地研究分支、工作树及未提交改动保留原位；GitHub标签只保存已提交内容，不包含未提交差异和ignored原料。未提交现场另有本机备份，不能据GitHub存在就清理本地。
- 不使用镜像推送或把所有活动分支整套推送；推送前核对明确的main与标签清单，不强制覆盖远端历史。

## 本机保留范围

Temp、backup、工具、音频、游戏资源、第三方Mod、发布ZIP、转储、个人配置与存档均不上传。保留的少量旧DLL、加载器及vendor组件属于已跟踪的工程依赖，其用途和许可证见现有正文，不为目录整理擅自移除。

当前源码还依赖本机77资源输入、工具链和未进入Git的研究原料；旧构建/打包脚本的文档路径尚待适配。克隆仓库能恢复受管文件及提交历史，不能直接恢复完整构建环境。按[本机资产索引](../archive/local-assets.md)和[开发说明](../engineering/development.md)逐项准备，缺料先报告，不从旧包猜测替代。

## 公开前的边界

现有历史回执包含Steam账号标识和本机用户路径，原始记录未改写；因此本次完整工程先保存为私有仓库。文本扫描未发现常见令牌/私钥，不等于对所有二进制格式作出了无秘密保证。

后续若公开，需要先确定本Mod授权条款及公开范围，并准备脱敏的公开版本；只在main追加删除记录仍会把原值留在祖先历史中。不要直接将当前完整历史切为公开，也不要为此擅改原仓库历史。
