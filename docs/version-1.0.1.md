# AC7DualSP 1.0.1

2026-10-15，用户反馈“一切正常”，要求停止游戏、更新版本并提交 Git，不制作发布包。正式版沿用已验证候选的功能逻辑，只统一版本和管理窗口标题；本轮不重新启动游戏。

## 相对 1.0.0

- 多人功能禁用：兵装、HUD、音效、输入与 F8 均受场景许可控制。共享菜单先识别 UIGameMode，再判断当前多人页面；不能直接用其多人父类判断场景。
- 英文体验：原生提示跟随游戏文本语言，英文说明换行保留单词间空格。F8 默认 Game Language，固定显示“语言选择/Select Language”。
- 管理简化：移除未购买 SP 试用；右下 HUD/名称变淡和直接选武器固定启用；中央简称可关闭，键盘可改键，手柄固定。
- 配弹范围 50% 至 100%，每 5% 一档，共 11 档。仅作用于下一份新草稿；单 SP 保留完整载量。
- 补给 HUD 在已确认交接后预建，初始化和事务收尾同回调提交，避免撤销刚接管的双 SP 行。

先前“补给后仅单 SP”的一次反馈，日志实际记录 SP2=NO WEAPON，用户表示可能记错；本轮双 SP 补给日志作为后续证据，不把旧反馈抹去。详细研究与失败修正保留于[候选记录](version-1.0.1-candidate.1.md)。
