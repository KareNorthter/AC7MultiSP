## 检索与维护

先定位主题，再在目标目录检索。日常默认排除evidence/references/vendor；查证据按链接、文件名或版本前缀定向读。历史全文按归档标签读取，不把旧“当前”“未构建”当今天状态。

新建、更名或合并文档时同时更新本索引和入链；先查已有唯一正文。合并后的旧全文移出日常树，恢复锚留归档索引，不保留第二份可编辑同义文档。
