# 多 SP 挂载设计

本文记录 AC7MultiSP 2.16.0 基线及当前CFA源码修订，适用原生 Steam build 9855922。正式交付仍为已测2.16字节，当前分支未构建或安装。完整旧研究和逐组合长表保留于[挂载设计归档](archive/multi-sp-mount-design-before-2.16.txt)。

当前47架有武装原版/官方 DLC 机体均有处理方向：23架常规布局、6架机外保留、2架原生外观旁路，合计31架有明确接入策略；另16架后置。31是策略覆盖数量，不代表31架七组合、所有任务与检查点均已实测。无武装 `f104av` 不在此47架范围内。

2.16用户反馈：CFA-44 三 SP 切换短暂卡顿后恢复正常，但选 ECM 时模型仍露出并展开；ADF-01 首次停光明显卡顿，后续仍轻微卡顿；其他功能总体基本正常。用户现已授权CFA专项修订，源码方案见下，效果尚待实测。CFA/F-22A 在准备页 SP2/SP3 移动光标时短卡、F-2A 多挂性能问题仍单列观察，不能从总体反馈推定已解决。

## 审美与功能取舍

| 项目 | 默认原则 | 已有经验 |
|---|---|---|
| 内外顺序 | 按实际尺寸、支撑和离架方向安排，大弹优先内翼/腹部，小弹优先外翼 | Su-30M2 腹4AGM、翼4AAM；MiG-29A 内侧 LAGM |
| 对称与平衡 | 双挂优先两侧成对；三挂空间不足时维持整体平衡 | MiG-29A 内LAGM2，外左HPAA1/右4AAM1；不把左右分种当统一模板 |
| 七种组合 | 三种单挂、三种双挂和三挂分别设计；少一种武器后重新利用空位 | 不能把三挂的半侧分区直接套到所有双挂 |
| 真实支撑 | 查原生 Socket、实际模型池、Body 与挂架，不只看编号或某一网格 | Gripen 原生腹挂不能因 SWP 独立导轨未覆盖就被否定 |
| 借位 | 可借未选兵装的真实支架，但显示与离架必须同点、保原父链并归还网格 | F-15E 既有换位；Su-35S 借 LASM 腹点给6AAM |
| 数量 | 空间允许时充分展示真实库存；不把待发窗口当全部模型上限 | F-35C 十二处8AGM、ADF-01 两处FAEB、ADF-11F 双挂补足QAAM/UAV |
| 机构与效果 | 炮体、舱门、主束、尾迹与充能粒子分别维护生命周期 | ADF-01 鼻口收回时停止主束，不连带撤销其他机体 TLS 策略 |
| 内外舱 | 优先机外明显模型连续，内部当前 SP 原生即可 | F-22A 保侧8AAM，普通Su-57保PLSL，Su-47/TGM原生 |
| 性能 | 隐蔽空架或轻微瑕疵不值得恢复高频骨操作 | F-22A 撤腹部骨显隐；X-02S 外形违和，撤销外观接管 |

允许轻微、不明显的穿模或动画瑕疵，仍须具体记录；严重离架穿插、悬空挂载、未知支撑或功能冲突不能用“允许轻穿模”放行。CFA 的隐藏目标也不能通过压低公共开盖进度来实现，否则可能阻断原生发射。

## 数量与映射

| 概念 | 含义 |
|---|---|
| 库存 | 剩余弹药，不由模型位置数决定 |
| 逻辑队列 | 原生每个槽的装填/冷却身份，运行时从真实 Group 读取 |
| 待发窗口 | 同时可装填或待发的数量，不一定等于模型池或锁定数 |
| 持久模型池 | 原生组件集合；资源 Socket 数只用于身份与集合核对 |
| 物理位置 | 当前布局真正使用的显示/发射点，可以少于逻辑槽或待发窗口 |
| 挂架与发射器 | 导轨、巢体、炮体、逐管口、效果源分别管理，不能都按消耗导弹隐藏 |

`SWP1/2/3` 是原生资源组，不是用户选装的 SP1/SP2/SP3；原生兵装配置是0/1/2。`spXX` 必须连同所属组解释。左右以机体坐标为准，负Y和正Y固定，不跟随观察镜头。

减位不缩减库存、窗口、锁定、齐射或冷却。多个逻辑槽可轮流共用物理点，因此少位组合不保证每次齐射都有独立模型消失。备用弹按真实库存、就绪和补装状态显示，不凭候选 Socket 总数强制挂满。CFA 原ADMM池126个发射组件、分侧选择42口，也不表示有126枚可见实体弹。

### CFA切换与ECM源码修订（未实测）

- 同机、同组合、同组件资源的普通切换保留分侧骨隐藏租约，避免Init前展开、提交后再隐藏；提交时重新核对隐藏状态，只修复被重置的分支。补给重配、换机、单挂和失败退出仍完整归还。
- 原生显隐请求继续记账，相同目标位不重复调用引擎；骨架Tick/NoSkeleton归还值未变时不重复调度。CFA只展示固定架，周期维护不再为126个空发射组件捕获ADMM弹药队列和计算就绪位图，弹药、冷却及离架映射保持原实现。
- ECM用SWP3组件双显隐位及两组机构骨隐藏兜底。依据 `evidence/sp-switch-animation-research.json` 的fa44/SWP3：七骨父索引为 `[-1,0,1,1,0,4,4]`，隐藏Body直接子骨 `SWPCover_01/04`，保留Body及其 `sp31` 发射点。运行时核对网格、骨架、骨数、骨名和父链；使用原生 `HideBoneByName` 的 `PBO_None`，不改碰撞、公共开盖进度或发射阶段。
- 此策略限多挂；单ECM继续原生。机身公共舱门仍可能随原生动作打开，目标是隐藏ECM伸出机构，不能以关门阻断发射。首次反射解析及原生兵装初始化仍有成本，不宣称卡顿已消除。

本轮只进行源码与差异审阅，未编译、新增或运行测试、安装、操作游戏。后续授权实测需覆盖三挂连续互切、ADMM/EML各与ECM双挂、ECM开启与持续、弹药/装填、补给转单挂及退出恢复；分别观察首次与后续切换，保留当前2.16对照。

## 继续适配的方法

1. 明确真实类、网格、父链、原生池和Socket，区分弹体、固定炮体、逐管口、UAV及效果源；缺资料及时报告，不按编号猜位置。
2. 分别设计三种双挂与三挂，列数量、内外/左右、真实支撑、显示/离架映射和接受的瑕疵。先用足已掌握的原生站，再评估借位。
3. 静态分区保留材质、Socket、非索引数据和全部LOD，核对主/深度/邻接边界；完成原编码字节复原、新名编码与独立解码回读。资源只留本机，不提交游戏资产或密钥。
