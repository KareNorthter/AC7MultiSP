保存与使用说明

本浏览器会尝试自动保留草稿，但正式交回前请点“保存可编辑网页”。下载后的 HTML 包含你的全部修改，双击还能继续编辑。

也可导出 JSON，之后用“导入方案”继续编辑。导入替换当前草稿；可用“撤销”恢复。文字意见会同时列出分组、文案和隐藏建议。

灰色的功能表示建议隐藏，编辑模式仍保留，纯预览不显示。点击问号能展开说明。纯预览中的操作只展示样例反馈。

布局、默认值和控件变化都只是设计建议。游戏内实现时，我会检查键鼠、手柄和小分辨率的实际限制。
