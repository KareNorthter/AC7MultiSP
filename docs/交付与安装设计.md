- 安装器单独嵌入项目现有授权说明供显示，不写入游戏、不混入通用ZIP；完整第三方许可证继续随原载荷保留。

## 用户流程

- 普通玩家：下载单 EXE → 检查更新 → 选择直接安装 → 自动找到游戏 → 点击安装或更新。同版点击安装可覆盖修复；不再检测或下载VC++/DirectX。离线仍可安装内嵌版本。
- Vortex 玩家：安装现有 AC7 游戏扩展，再安装本配套扩展 → 下载通用主包 → 按提示补齐 AC7 专用 UE4SS → 完整退出游戏后部署。免费账户网页确认下载可接受，用户无需手动解压、复制或编辑配置。
- 手动玩家：从 EXE 导出同一份通用主包，将 ue4ss 和 Game 合并复制到游戏根目录。必须先有正确 UE4SS。主包不包含共享前置和个人配置；详细说明随 ZIP 提供。

放弃对鼠标飞控启动器“附加 Mod”导入的适配，仍保留与鼠标飞控共用已核验加载器的能力。不要同时用多个工具管理同一份 MultiSP；本阶段不自动迁移其他管理器的文件。

## 一套载荷，两种交付

`src/package_delivery.py` 输入正式发布 ZIP 和对应发布回执，核对整体摘要、成员集合、每文件大小和摘要、运行回执与 PAK。只派生包装，不重编译、不改原包或旧回执。

通用 ZIP 根目录直接是游戏相对路径。包含 `ue4ss/Mods/DualSP`、专用挂架 PAK、独立 `enabled.txt`、说明、清单和 Vortex 映射。DLL、UI、Lua 和 PAK 同版成套，不打包 profiles、存档、日志或其他 Mod。

Vortex 映射保留已验证的 Engine Injector 根目录部署作为无配套扩展时的后备。配套扩展另注册明确的本产品安装器，解决依赖流程忽略包内覆盖指令时的目录识别问题；本轮 r4 已核对主包31文件和前置25文件的实际部署，不沿用旧封装的实机结论。

通用 ZIP 和安装器均登记 Nexus 来源、条目3797、游戏及版本；每个属性使用独立覆盖键，避免多属性相互覆盖。只登记真实条目，不伪造尚未上传的 Nexus 文件 ID。本地预览与线上版本关系、真实在线更新仍以正式上传后的文件关系为准。首次 r4 因未登记来源出现版本栏黄色提示，r5 已补齐元数据。

EXE 将每份原始文件作为独立资源嵌入。安装不导入、不依赖外部 ZIP；仅导出时生成通用 ZIP。导出内容固定为本 EXE 内含版本，不把在线最新版本号贴到旧资源上。封装 ZIP 与 EXE 导出 ZIP 的压缩时间戳可不同，逐文件内容应一致。

工具版本独立于 Mod 版本；后续正式功能号由主线整合统一，不回改 2.24.1 或其他已验收版本。

已有手装的接管仍须先备份并迁移，不能通过简单叠加冒充完整停用；旧手装恢复问题已有旧版验收依据，本轮不改旧回执。

从 EXE 改用 Vortex 时先用 EXE 卸载，再导入通用 ZIP。卸载后保留的个人配置目录不构成旧程序残留；检测只拦截脚本、二进制、启用标记或专用 PAK，不因个人配置目录还在而阻止安装。

## EXE 安装与维护

源码位于 `src/delivery/setup`。使用 Windows 自带 .NET Framework 图形界面；安装器本身不依赖游戏所需 VC++/DirectX，也不要求用户装 Python 或额外 .NET 桌面运行库。优先按普通用户权限运行，权限不足时报告具体错误，不自动改权限或预先提权。

从 Steam 注册表、游戏库及应用 502500 清单查找游戏，自动选择有效目录，支持失败时手动选择及通过目录文字链接更改。检查 Ace7Game.exe 与 PAK 目录。0.2.0按用户要求移除微软运行库初筛及下载入口。

安装前核对版本，禁止自动降级；已有 alpha 可按三段基础号比较。遇 Vortex 部署记录、鼠标飞控附加 Mod 记录或需写入的文件链接，停止并提示使用原工具。现有未知脚本不自动清空；按旧运行回执移走废弃程序。个人配置、改键、方案由 Mod 首次启动迁移，安装器不代替配置迁移。已有自定义提示音保留。

写入前同卷暂存并校验，原文件备份至游戏目录中的 `AC7MultiSP-backup/<事务号>`，记录持久事务日志，使用同卷替换和独占锁；失败时按日志恢复，发现外部修改或损坏备份时停止。新文件或卸载文件移入备份，不永久删除；备份不自动清理。

EXE 安装记录为游戏根目录 `AC7MultiSP-install.json`。卸载仅处理记录中的产品程序/资源并移入备份，修改过的已登记程序也备份移出，以免留下可继续加载的半套程序；个人配置和所有共享前置保留。没有本工具归属记录时不擅自卸载。

恢复只处理唯一未完成事务，不自动恢复多个疑似记录。备份是恢复资料，不提供任意跨配置版本降级功能。卸载和恢复均要求游戏退出。

## 更新入口

游戏内和 EXE 都提供同样的两种方式：

1. 已通过 Vortex 安装：前往 Nexus，在 Vortex 中检查并更新。
2. 其他安装方式：下载最新安装包，退出游戏后运行。

仍从固定 `stable.json` 读取正式版本和说明，保留现有 schema=1 及 downloads 字段；发布 EXE 后可新增 `installer_downloads` 数组，字段与 downloads 相同，另要求每项 `format` 为 `exe`。新客户端优先用它，旧客户端继续读 ZIP。未发布 EXE 时明确显示 ZIP，不把 ZIP 链接标成已可用 EXE。

EXE 在后台检查，失败不阻挡离线使用；只打开已登记 HTTPS 来源，不下载后自动执行。游戏内网络功能仍只在后台线程检查，渲染/游戏线程不联网；新增 Nexus 固定条目允许名单，不放开任意主机。

先上传并核对所有实际成品，再更新 Pages 清单。本轮不改 Pages、R2、蓝奏云或 Nexus，也不把源码候选写成已发布安装器。
