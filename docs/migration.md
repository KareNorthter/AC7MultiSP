## 迁移方式

先复制保留项并逐文件核对 SHA256，再整理说明与路径，建立当前版本 Git 基线，最后回收旧目录。迁移中对会改动的既有副本进行了临时备份。运行时八个文件和原始当前安装包均保持字节一致，见[基线记录](../Release/baseline-0.1.7.json)。

当前布局中的可用入口已解除旧实验目录依赖：工具链按脚本位置定位，研究工具从当前 `tools` 读取依赖，本机更新使用根目录安装入口。存档路径跟随当前 Windows 用户。

已完成回收：15 个明确目录和 12 个明确文件，共 27 项。没有清理共享父目录、其他项目备份或游戏内文件。第三方源码保留，两个重复下载 ZIP 回收；`Temp/` 仅留下迁移复制清单与核对概要。回收站未清空，清理不代表已经释放这些文件占用的磁盘空间。

Git 保留正式运行 Lua 的原始字节，避免换行转换破坏基线 hash；工具二进制、个人备份和重复载荷不入库。初始版本保留了本机可用依赖，若日后从 Git 恢复到其他目录，应先按[开发说明](development.md)补齐工具并同步安装载荷。
