AC7DualSP 1.0.2 — 模组兼容性验证摘要
日期：2026-10-15；游戏：Steam build 9855922；范围：单人战役/自由任务。

本版变更
修正 STANDBY 换机后 UI 消失；从实际机体实例读取兵装，按实际 WeaponID 计算部件与限制；
读取外部模组提供的兵装名称；支持机体类名大小写差异与涂装派生类；换机结束旧机体错误上下文。
管理快捷键可配置，本机 F6，与鼠标飞控 F8 分开。武器核心复用 1.0.1，核心逻辑未改。
整理期间根据新反馈增加异步换机等待：预览未更新时提示等待并暂停原生单 SP 确认，就绪后接入双选，
10 秒超时明确报错。此项只在源码完成、语法核验通过，尚未部署或实玩，不计入下面的通过成果。
等待时遮蔽原生单 SP 列表/参数/光标，显示 SP1/SP2 占位与加载提示；已有双栏保持到资料就绪。
正常过渡尽量不暴露原生单 SP 选装/HUD，真正接入失败或超时允许明确报错后恢复原生单 SP。

当前合装边界
保留 Adler A/B、独立 J-20A、飞控、比例制导、FOV、部件、Hex 和 TLS 样本，共 16 个 PAK。
外部 PAK 原样；使用作者共用武器/名称/皮肤表与本项目生成的本地精简机库表。
机库表为 47 条原战役记录加三条新增，运行日志确认共 50 条；不装会列出未安装机体的完整 195 条表。
PW-MKI 位于此前批次备份，未与当前组合同时启用；DLC 购买条件不改变。

限制与待观察
UAV/ECM 不支持双挂；切离 TLS 会结束光束；任一时刻只显示一种 SP 挂载模型。
J-20 Spare/Strider 会改变实际兵装，菜单名称/基础载量仍来自数据表，不能保证任意涂装动态展示完全匹配。
快速换机时日志有预览模型身份不符，用户随后反馈偶发单 SP、重选恢复；源码已增加显式等待，效果待验证。
VR、多人、长期多次补给及其他大型整合包不在此次通过范围内。

版本与交付
本次在仓库统一 VERSION、Lua 加载标记和 UI 标题为 1.0.2，并编译仓库内 UI；另补上待验证的换机等待修订。
按用户要求保留游戏运行，不执行安装器、不热替换运行文件；正在运行的已验证候选仍显示 1.0.1。
无需发布包：未生成 ZIP、未推送远程。后续退出游戏再部署，需重点复测快速换机，不将新等待逻辑当作已验证。
核心来源：dist/DualSP/cores/1.0.1/DualSP.dll；原始第三方资源、存档和配置不提交 Git。
