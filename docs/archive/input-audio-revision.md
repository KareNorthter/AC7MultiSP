## 音效：重建时丢弃了尚有播放引用的锁定槽

现场只读检查发现锁定组件四个音效计数为 `[1,0,0,0]`，两个现存锁定槽的四个播放标记均为零，且均处于状态 0。它说明存在已失去槽标记的播放引用，不能再按“按键没释放”解释。

原生调用链为：

1. 兵装初始化 `0x81E810 → 0x882E40 → 0x4C6D10`。
2. `0x4C6D10` 清空旧槽数组并创建新槽，没有停止旧槽音效。
3. 单槽的音效播放/停止通过 `0x4BF200/0x4C00C0` 配对维护槽标记与组件计数；计数归零才发送对应停止事件。其事件名包括 `HUD_MISL1/2_SEEKER_P/S` 与 `HUD_MISL1/2_LOCKON_P/S`。
4. 原生另有逐槽音效收尾 `0x4C98A0 → 0x4C0080`；飞机停用流程在重置锁定前会调用它，而当前模组的运行中兵装重建没有此步骤。

候选 6 在每次核心重建和 Lua 出击/补给初始化之前调用这条原生收尾链，旧槽仍存在时发送配对停止事件，然后核对四个计数归零，再重建兵装。若计数仍有残留，明确停止并报告需要重新开始任务，不强行清零、不循环补发停止事件、不使用全局静音。候选 5 已产生残留的旧任务不会被热修复；新版本需重启游戏后使用。
