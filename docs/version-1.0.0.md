# AC7DualSP 1.0.0

返回[项目入口](../AGENTS.md)。2026-10-14，产品正式命名为 **AC7DualSP**。

## 本版范围

用户确认 `0.1.9-performance-candidate.1` 测试没有问题后，将同一运行逻辑整理为 1.0.0。保留双 SP 独立弹药/冷却、原生准备/补给双选、F8 管理、直接选择、部件载量预览及 SP2 提示音。

本次只更改版本、名称和管理窗口可见标题，更新说明及发布流程。武器核心复用 `cores/0.1.9/DualSP.dll`，没有重新编译；UI 为更新标题重新构建。内部 DualSP 文件名、导出、配置格式保持兼容。

性能候选已包含中央字号放大约 11%、独立绿色样式、菜单扫描缓存、静态显示按变化更新，以及补给页面提前接入。没有凭空给出帧率提升数字，变红的原始触发条件也没有被明确复现。详见[性能依据](performance-polish.md)。

## 安装包

`Release/AC7DualSP-1.0.0.zip` 为独立手动安装包，包含当前 Mod、专用加载器、SP2.wav、第三方许可、VC++ x64 / DirectX 离线依赖及 [TXT 新手说明](AC7DualSP-安装说明.txt)。不含个人配置、存档、日志、开发工具或命令行安装入口。

只核对了 Steam build 9855922，目标 Windows 10/11 x64 单人模式。不要直接覆盖其他项目的加载器或把旧核心与本版 Lua 混装。旧配置可沿用，双模型、VR、多人和第三方机体不在保证范围内。
