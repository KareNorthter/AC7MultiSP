AC7MultiSP 2.3.1 开发测试版
《皇牌空战 7》多特殊兵装 Mod
本机已整套安装2.3.0开发测试版，完整编译和安装所需检查通过，2.2.2用户实测反馈“基本没看到问题”；2.3.0任务内快捷键已实测正常；2.3.1全场景F7及挂载布局候选尚未安装，用户要求保持游戏运行。无需再次复制安装；原2.2.2模组及存档已备份，安装保留个人配置和其他模组。沿用已迁移的管理参数5配置。新Lua不能与旧2.0.0 DLL混装。尚未制作新ZIP，手动安装步骤供后续完整发布包使用。

一、开始前
支持 Windows 10/11 64 位、Steam 版游戏 build 9855922。
仅面向单人战役和自由任务；其他游戏版本、VR、多人和第三方机体未保证兼容。
请先正常启动过一次原版游戏，再退出游戏。整个安装过程不需要命令行。
本 Mod 保留普通导弹，可选择 1 至 3 种特殊兵装，分别保存弹药和冷却。

二、找到游戏文件夹并备份
Steam 库 → 右键 ACE COMBAT 7 → 管理 → 浏览本地文件。
打开后应能看到 Ace7Game.exe，这里就是下文的“游戏根目录”。
不要放进 Paks、Binaries 或 Win64 文件夹。
例如：E:\SteamLibrary\steamapps\common\ACE COMBAT 7

若根目录已有 dwmapi.dll 或 ue4ss 文件夹，先将它们复制到游戏目录以外备份。
旧版 DualSP 的配置是 ue4ss\Mods\DualSP\profiles.json，也请备份。
若这些文件来自其他 Mod 或其他 UE4SS 版本，请先停止安装：本包使用专用加载器，
不能保证与普通 UE4SS 或其他武器 Mod 混用。不要直接覆盖来尝试兼容。

三、安装运行库
先把本 ZIP 完整解压到一个普通文件夹，不要直接在压缩包里双击运行。
1. 双击 Runtimes\VC_redist.x64.exe，按提示安装。
   若提示已安装相同或更高版本，关闭即可，不要卸载现有版本。
2. 双击 Runtimes\DirectX\DXSETUP.exe，按提示完成安装。
   不要单独移动 DXSETUP.exe，它需要同文件夹中的 CAB 文件。
   即使电脑已有 DirectX 12，也可能需要这里的旧版游戏组件。
3. 安装程序如提示重启，请先重启电脑。
正式 ZIP 提供这两个微软离线安装程序，不需要另找 DLL 下载网站；本机升级不重装运行库。

四、首次安装
打开本包的 GameFiles 文件夹，将里面的 dwmapi.dll 和整个 ue4ss 文件夹
复制到上面的游戏根目录。复制的是 GameFiles 里面的内容，不是 GameFiles 文件夹本身。
复制完成后至少应看到：
  游戏根目录\Ace7Game.exe
  游戏根目录\dwmapi.dll
  游戏根目录\ue4ss\UE4SS.dll
  游戏根目录\ue4ss\Mods\mods.txt
  游戏根目录\ue4ss\Mods\DualSP\Scripts\main.lua
  游戏根目录\ue4ss\Mods\DualSP\bin\DualSP.dll
  游戏根目录\ue4ss\Mods\DualSP\bin\DualSPUI.dll
  游戏根目录\ue4ss\Mods\DualSP\Audio\SP2.wav

用记事本打开 ue4ss\Mods\mods.txt，应包含一行：
DualSP : 1
注意：产品名是 AC7MultiSP，但内部目录和启用名称仍是 DualSP，不要重命名。

五、从本项目旧版升级
先退出游戏并完成第二步备份。仅适用于原本使用本项目专用加载器的旧 DualSP。
从正式 1.0.2 升级时会备份旧配置并迁移到三 SP，旧第三槽为空；若原武器键位已占用数字 4，请先在旧版改为其他键再升级。开发版将旧管理参数迁到第5版，保留方案和键位，移除中央提示开关；双SP默认50%、三SP默认33%，原配置另存 profiles.before-management-options.json。
把 GameFiles 内的内容复制到游戏根目录，选择替换同名文件。
本包不含 profiles.json，不会用默认配置覆盖你的旧配置；不要先删除整个 DualSP。
若 mods.txt 中原先还有其他 Mod，不要覆盖该文件：保留原文件，确认或补上
DualSP : 1 即可。同名加载器和其他 Mod 的兼容性仍需自行确认。

六、启动与操作
从 Steam 正常启动游戏，默认按 F6 应看到“AC7MultiSP 2.3.1 管理”。
升级时保留已配置的管理键；旧配置若明确保存为 F8，仍使用 F8，不会强制重置。
手柄可用 Back + Y 打开管理界面。任务中打开管理界面会暂停。
准备页依次选择 SP1、SP2、SP3，后两槽可选 NO WEAPON；实际携带 1 至 3 种。
每步确认一次，之后进入 STANDBY。原生选装请用键盘或手柄。
默认键盘 1/2/3/4 对应普通导弹/SP1/SP2/SP3；手柄十字键左/上/右/下对应这四项。
原游戏切换键继续循环，跳过未选和耗尽的 SP。中途降落补给可重新选择，YES 确认起飞。

七、管理与任务内调试
F6 管理总开关、弹药比例、实验挂载、语言、键位和日志；修改后点击“保存设置”。
“启用 AC7MultiSP”保存后重启游戏生效。关闭后恢复原生出击、补给、武器切换和HUD；仍保留管理页，以便重新开启并重启。关闭总开关不会卸载加载器。
单SP保持100%；双SP默认各50%，可在50%至100%之间滑动；三SP默认各33%，可在33%至100%之间滑动，步进1%。先计算已装部件，再按比例向上取整；零弹药仍为零。设置在下一次出击、补给确认或调试应用时配弹，不会因普通保存给当前任务补弹；旧检查点保留原比例和库存。
“多 SP 武器模型同时挂载（实验性）”默认开启，无需重启游戏。任务内保存后，在下次出击、重启任务、检查点重试、补给确认成功或调试换装时生效；菜单保存则供下一次出击使用。仅原版F-15E、F-35C、Su-30SM尝试同时显示多SP；其他机型开启也无效果。关闭后全部使用原生单SP外观，不影响多SP弹药及切换。保存本身不补弹。模型适配失败会停止接管并归还原生状态，原因显示在管理页；此新增回退路径仍待实机验证。
模组开启时中央HUD简易武器信息固定开启，不再有独立开关，仍跟随游戏HUD显隐。准备页当前SP弹药行全亮，其余两行半透明。
管理界面支持纯键盘：Tab / Shift+Tab 移动，方向键选择，Enter 激活，空格勾选，Ctrl+Tab / Ctrl+Shift+Tab 切页，Esc 先关闭下拉框、再关闭界面。
任务中管理界面会暂停；关闭时只解除它创建的暂停，原有游戏暂停保留。失败会明确显示错误。
“调试”页可选择当前机体已购买的 1 至 3 种 SP，点击“应用 SP 方案并补满”立即重配 SP，并选回普通导弹。
调试保留普通导弹弹药/冷却、机炮、干扰弹和已有检查点，不保存成个人方案；之后产生的新检查点可记录调试方案。
请等已发射武器结束后再换装；活动武器登记非空会明确拒绝。它不保证追踪切换前所有仍飞行的弹体。
调试暂不支持任务内换飞机，不修复机体，也不能代替真实出击和补给。
默认语言跟随游戏，也可手动选择中文或英文。
设置及按机体保存的方案位于 ue4ss\Mods\DualSP\profiles.json。
通常不需要手改 JSON。备份或恢复该文件前请退出游戏。
新版默认 F6，与 AC7MouseAim 的 F8 分开。旧配置如仍使用 F8，可退出游戏后，
用记事本将 profiles.json 已有的 management_key 改为 117（F6；119 代表 F8），保存后启动游戏。
不要同时把 F6 设为本 Mod 的其他武器选择键；旧配置若已将 F6 用作武器选择，请先调整。
手柄管理组合键不变。

快捷测试（2.3.1）
Ctrl+Alt+F6：按原生列表中的A、B、C次序轮切 A→B→C→AB→AC→BC→ABC。自动跳过未购买或仅能单挂的组合；每次按已保存比例补满SP、切回普通导弹，保留普通弹药、机炮、干扰弹、个人方案和检查点。
Ctrl+Alt+F7：机库、补给、任务暂停和飞行中均可即时开关“多SP武器模型同时挂载”并保存设置，不补弹、不更换当前SP。仍只适配F-15E、F-35C、Su-30SM。
无需打开管理页；按住只触发一次。执行结果或拒绝原因会短暂显示。F6在补给/过场/检查点交接、游戏原生暂停及仍有在途武器时暂不执行，也不排队；返回正常飞行后再按。F7不受这些换装限制，无有效机体时先保存，机体就绪后应用；总开关关闭时仅保存。普通F6仍打开管理界面。

八、已知限制与排查
2.3.1合入三机型挂载布局候选，详见版本说明。F-15E/F-35C需观察穿插与全动画，Su-30SM外侧QAAM导轨呈现仍待处理。
机库预览转镜头明显掉帧：用户报告模型开关两种状态均卡顿；根因未定，已列为后续专项测试，本次不声称修复。
原版 Su-30SM、F-35C、F-15E 已适配任务中多 SP 模型共存；其他机型仍按原生当前 SP 呈现，不能据三选成功判断模型已全适配。2.2.2修复机库和补给挂载预览的场景衔接：随SP候选、已确认前置槽、无兵装及返回操作更新；退出武器页后，STANDBY/PART/SKIN/EMBLEM等机库界面统一显示保存方案。补给确认后保持到起飞过渡，开场玩家机体就绪后提前显示方案。预览共用实验多挂开关，只改变外观，补给确认成功后才实际换装。预览失败回退原生显示并在管理页提示，原有选择、配弹及补给继续运行。2.2.0已发现SKIN/起飞漏接和PART切页闪回，本版还补上页面激活即时刷新、原机体模型组件重建和开场玩家快速定位；2.2.2已有用户基本正常反馈；若过场使用尚未识别的独立替身则仍保持原生外观。本次未提供逐机型、任务及动画测试明细。
已验证 F-15E 的 TLS→普通导弹可跟随并自然结束；TLS→其他 SP 仍会结束光束。UAV、ECM 仅支持单挂。
中央和右下武器名未就绪时亮度降低，就绪后恢复，这是正常提示。
2.0和2.0.0已通过用户实测。当前2.3.0完整编译和安装所需检查通过、已安装，任务内快捷键已实测正常；2.3.1新场景和新布局待测试；2.2.2用户实测反馈“基本没看到问题”，但不能扩大为所有故障回退、任务和机型均通过。
正常换机若模型尚未就绪，会短暂显示多 SP 加载占位，等待后自动接入。
真正接入失败或等待超过 10 秒时会记录错误并恢复原生单 SP；请保留日志反馈。
多人模式下本 Mod 功能禁用，但加载器仍存在，不代表联网或反作弊兼容保证。
已抽样验证的第三方模组及范围见“版本说明.txt”；第三方模组需要另行安装。

管理键无反应：先确认是否改过管理键，再检查复制位置、mods.txt、运行库和加载器。
启动失败或出现错误：退出游戏，保留 ue4ss\Mods\DualSP 下的 mod.log、
native.log，以及 ue4ss 下实际生成的加载器日志，连同游戏版本和复现步骤反馈。
不要反复覆盖、不明来源下载单个 DLL，或关闭系统安全防护来绕过错误。

九、卸载或恢复
先退出游戏，把 ue4ss\Mods\DualSP 文件夹移到游戏目录外备份，
再用记事本从 ue4ss\Mods\mods.txt 移除 DualSP : 1 这一行。
只有确认 dwmapi.dll 和整个 ue4ss 都仅供本 Mod 使用时，才将它们也移出游戏目录。
其他 Mod 共用的文件不要移动。恢复旧版时，将第二步备份放回原位置即可。
卸载不需要改动游戏存档；建议保留 profiles.json，便于以后恢复设置。
