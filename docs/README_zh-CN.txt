AC7MultiSP 2.22.1

2.22.1更新说明（相对正式2.22.0）
• 管理界面整理为基础功能、视角、调试三页，日志在调试末尾展开；手柄与键盘锁定注视分别设置，默认关闭。
• 视角保持默认Ctrl+Alt+F6；切换SP组合、任务多SP模型快捷键默认未绑定，可在配置文件指定；NEXT模式仅在管理页选择。
• 新配置默认机炮齐射开启、中心白点关闭、兵装文本切换后显示1秒。视角保持默认关闭，L3/R3操作保留。
• 配置修订19不兼容旧格式：先完整备份旧配置及个人方案，再生成新默认值，不迁移；已有有效配置19正常保留和保存。
• 修复F/A-18E TGM完整借架的Socket引用，采用r2资源；77资源/154成员离线资格与实际字节绑定，其他152成员及28架196布局保持。

用户已确认当前安装成果“没问题”，正式版本统一为2.22.1。核心和模型资源沿用已验收字节，UI仅等长版本文字变换；研究临时编号不进入正式发布序列。

让一架飞机携带多种特殊兵装：单人战役/自由任务中可选择1至3种SP，分别保留库存、装填、HUD和切换。多人模式停用。原生Steam build9855922，Windows10/11 x64。

安装
1. 完整解压，先退出游戏。Steam→游戏→管理→浏览本地文件，找到Ace7Game.exe所在目录。
2. 备份已有dwmapi.dll、ue4ss及同名挂载包。升级保留ue4ss\Mods\DualSP\profiles.json，不删除整个DualSP目录。
3. 需要时运行Runtimes\VC_redist.x64.exe和Runtimes\DirectX\DXSETUP.exe，保留DirectX同目录CAB；已有同版或更新运行库无需卸载。
4. 将GameFiles内的dwmapi.dll、ue4ss和Game合并复制到游戏根目录，不要复制GameFiles文件夹本身。挂载包路径为Game\Content\Paks\~mods\AC7MultiSP_Mounts_P.pak。
5. 原mods.txt若还有其他Mod，不覆盖整个文件，只保留或补入DualSP : 1。本包使用AC7专用UE4SS加载器，共享加载器须核对后合并。
6. 通过Steam启动，默认F6打开管理界面；无需Python或编译工具。旧格式配置和个人方案先完整备份，再重置为配置19，不做迁移；已有有效配置19正常保留。

卸载时移出DualSP目录及上述挂载包，并移除启用项；共享加载器仅在其他Mod不再使用时移出。本包不含个人配置、存档、日志、转储、诊断工具或第三方机体Mod。

基本操作
• 新配置默认机炮齐射开启、中心白点关闭，兵装文本切换后显示1秒；手柄/键盘注视及视角保持分别默认关闭。
• 原生准备页依次选择SP1/SP2/SP3，后两项可选NO WEAPON；未购买的SP不进入普通选装列表。左下显示光标兵装的原生长说明并跟随游戏语言。
• 键盘默认1/2/3/4选择普通导弹/SP1/SP2/SP3。十字键左/上/右/下对应同样顺序，可单独关闭；X保留原生轮切。
• F6或Back+Y打开管理，任务中打开会暂停，关闭只归还本面板拥有的暂停。基础功能、视角、调试三页；日志在调试末尾展开。
• 任务/机库模型开关只控制外观，不影响多SP选择、弹药和注视。任务模型快捷键默认未绑定，可通过配置文件指定；关闭机库模型可恢复原生展示以改善机库低帧。
• 轮切调试SP组合默认无快捷键；Ctrl+Alt+F6切视角保持；Ctrl+Alt+F5切机炮齐射，支持原生机枪联动MGP/PLSL，HGP及不同SP真正并发不支持。
• 在管理视角页切NEXT原生/VR模式，不设快捷键；VR表示视野中心优先。与鼠标飞控并用时，请关闭其F2 HMD目标功能以免争抢目标。白点、注视和视角保持可分别设置。
• 视角保持默认关闭。L3/R3镜头操作固定保留：L3单独按下并松开回正、结束当前锁定注视；R3短按切普通视角、长按0.3秒切视角保持并保存，松开不再换视角。双摇杆只干扰弹。独立中键回中和5%～200%灵敏度可配置；角度自动回正及滑条已移除。
• 手柄/键盘锁定注视各自默认关闭；启用对应来源后Y长按0.2秒开始/结束，短按仍切目标并随新目标注视。键盘使用游戏实际绑定的原生注视键，按一下开始、再按一下结束；不再提供单独的注视功能启闭自定义键。暂停、失焦、管理、目标消失、特殊镜头或离场会结束注视。
• 普通保存不补充当前弹药；调试“换机并重开任务”会重新开始整关。支持检索三SP目录完整的Mod机体，使用当前真实引用和涂装SP，不授予DLC/购买许可。
• 第13关113使用任务指定SP，离开恢复；同地图自由飞行213不受影响。第12/14关保留多SP。

已知边界
• 首次载入、选装页面、结算箭头和部分机型仍可能卡顿；F-2A模型性能及其他偶发退出继续按独立现场处理。
• F-22准备页已定位的字段名生命周期问题已在本Mod路径规避，不代表通用加载器或所有第三方Mod已修复。
• 本轮验收不扩大为全机全组合、所有Mod兼容或固定帧率保证。机体Mod不适配多SP模型时可关闭模型外观，具体兼容行为仍取决于Mod本身。
• FALKEN激光/尾迹期间切换请求忽略，结束后重按；PLSL/MGP齐射切槽可能有间隙。

SP2.wav为用户提供的非原创提示音，本项目不授予额外权利。运行库保持微软原安装文件，许可证随包提供。
