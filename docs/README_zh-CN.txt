AC7MultiSP 2.19.5 测试候选

用户反馈此前2.19.4镜头功能正常；当前2.19.5新增普通换视角及长按Y的衔接修订，实际效果待测试；仅在第二个“按键”页开启camera-hold后提供子设置，保存后生效。

• “替换R3按下功能”默认关闭。关闭时恢复R3原生功能；开启后短按松开回正，长按满0.5秒立即换一次视角，无需松开，随后松开不再回正。

• 手柄松杆或键鼠松开游戏“视点操作模式”键（默认Alt）后保持方向；不改写游戏键位。短按切换目标保留方向，真正的原生长按注视和模组持续注视仍优先。
干扰弹始终保持原生；启用R3替换时，双摇杆另可同时回正。关闭camera-hold后各子功能停用；暂停、管理、失焦及特殊镜头期间归还原生。新源码协议11/配置10/镜头子协议3，旧9首次启动先备份profiles.before-camera-input-options.json，再补默认关闭的R3开关；旧灵敏度超过200时限为200，其他有效设置保留。核心/UI/Lua需成套更新，旧冻结产物及回执保留，当前升级至2.19.5。

本轮额外修订已接收至2.19.5成套构建、通过现有检查并安装，新效果待测试：开启camera-hold时，普通第一人称/座舱/第三人称切换接续观察方向；长按Y开始注视直接从当前方向转向目标，松开后回到保留方向。所有原生回正屏蔽仅在camera-hold开启时生效，主动回正仍有效。手柄X正常切换目标注视不再弹“开启/关闭”提示，错误/无目标及键盘提示保留。新修订效果待实测。

让一架飞机携带多种特殊兵装，在任务中随时切换。
适用：Windows 10/11 64位、Steam版《皇牌空战7》build 9855922，单人战役和自由任务。
其他游戏版本、VR和多人不在兼容保证范围内。多人中功能会自动停用。

功能
• 在原生准备界面选择1至3种SP，普通导弹仍可使用；补给时可以重新选装。
• 各SP分别保存弹药和装填状态。单SP保持完整弹量；双SP默认各50%，三SP默认各33%，可在管理界面调整。
• HUD显示当前兵装和装填信息；支持原生循环切换及四项直接选择。
• 实验性“多SP武器模型同时挂载”尽量保留已选武器的外观。显示方式按机体适配，部分内置弹舱仍使用原生模型切换。
• 管理界面可设置中文/英文、键位、弹药比例和模型功能，也可查看日志。
• 调试页可临时重配SP、补满SP弹药，或换机并从头重开任务。调试列表含未购买和缺DLC许可项，允许尝试；不授予购买记录或DLC许可，也不保证能生成该机体。
• 第13关自动使用关卡指定兵装，暂时停用多SP接管，离开后自动恢复；不改个人设置。同地图自由飞行不受影响。

安装
1. 完整解压本包，退出游戏。Steam→游戏→管理→浏览本地文件，找到包含Ace7Game.exe的文件夹。
2. 备份已有dwmapi.dll、ue4ss文件夹，以及Game\Content\Paks\~mods中的同名挂载包。
   旧个人配置在ue4ss\Mods\DualSP\profiles.json。升级时保留它，不要删除整个DualSP文件夹。
3. 需要时运行Runtimes\VC_redist.x64.exe和Runtimes\DirectX\DXSETUP.exe。
   如已有同版或更新的VC++运行库，无需卸载。DirectX安装程序需要同目录CAB文件。
4. 将GameFiles里面的dwmapi.dll、ue4ss、Game三项合并复制到游戏根目录，不要复制GameFiles文件夹本身。
   模型包最终位置必须是Game\Content\Paks\~mods\AC7MultiSP_Mounts_P.pak。
5. 初次安装启用列表已包含DualSP : 1。若原ue4ss\Mods\mods.txt还有其他Mod，不要覆盖该文件，只补入或保留这一行。
6. 通过Steam正常启动。默认F6打开管理界面；旧配置会保留你原来设置的按键。
   内部目录和启用名称仍为DualSP，请勿改名。无需Python或编译工具。

已有其他UE4SS加载器或同名代理DLL时，请先核对再合并：本包使用AC7专用加载器，普通UE4SS不能直接替代。
本包不含个人配置、存档、日志或第三方Mod。卸载时移出DualSP文件夹和上述挂载PAK，并移除DualSP : 1；共享加载器只在确认没有其他Mod使用时再移出。

基本操作
• 准备页依次选择SP1/SP2/SP3，后两项可选NO WEAPON。原生选装使用键盘或手柄。
• 键盘默认1/2/3/4：普通导弹/SP1/SP2/SP3。
• 手柄十字键左/上/右/下：普通导弹/SP1/SP2/SP3；原生循环切换键仍可用。
• 可选单次按键持续注视目标：第二个“按键”页开启手柄X替换（默认关闭），或在按键页设置独立键盘键（默认未绑定）。按一次开始、再按一次停止；Y保持原生操作。开启X替换后用十字键或原生键盘键切SP。暂停、打开管理、失焦或目标消失时自动停止。
• 本候选首次启动先备份profiles.before-camera-hold.json，再迁移配置；安装保留个人设置和既有注视设置。
• F6，或手柄Back+Y：管理界面。任务中打开会暂停，关闭后只解除本界面创建的暂停。
• 默认Ctrl+Alt+F6轮切调试SP组合并补满；Ctrl+Alt+F7即时开关多SP模型。键位可自定义。
• 普通“保存设置”不会给当前任务补弹。任务换机使用“换机并重开任务”，会重开整关。
• 若模型适配卡顿，可关闭“多SP武器模型同时挂载”，仍保留多SP兵装和切换功能。

已知问题与待优化
• CFA-44：用户确认2.19.3优化有效，正常切换约26ms、双发暂未复现，接受首次峰值。2.19.4继续减少锁定/持续效果等重复读取，计时修订4；10ms目标与全机体双发消除仍待测试。
• 任务结算界面的箭头卡顿已明显缓解，但仍有轻微卡顿，尚未完全解决。
• ADF-01：TLS及尾迹未退场时直接忽略切换请求，结束后需重新按键，不自动排队切换，也不提前停光。实际体验待测试。
• 部分机体选择SP、首次加载或进入任务时仍可能停顿；CFA-44/F-22A在SP2/SP3页面移动光标的卡顿仍待专项定位。
• F-2A多SP外观的性能仍待优化；少数机型、特殊机构或挂点不足的组合暂保原生外观。Su-47、Su-57 TGM和X-02S使用原生外观。
• 曾有机库偶发退出报告，根因未定。并非所有飞机、组合、任务和故障恢复都已逐项验证。
用户已反馈目标注视正常；2.19的CFA定向优化已确认有效；第13关更正和注视选项移页沿用2.18。其余上述问题继续保留。本候选为新构建，未获实机验收；R3短按漏放换视角也已修订，均待测试。

与其他Mod的兼容性
• 早期版本曾实测鼠标飞控AC7MouseAim、FOV、比例制导，以及PW-MKI、Adler A替换机的部分场景可用；2.16没有对这些组合进行完整复测。
• J-20替换机曾确认模型/涂装正常，但只使用原生单SP；不能据此推断所有第三方机体支持多SP。
• 皮肤、模型、HUD、兵装表、发射逻辑或输入Mod可能修改同一资源/接口。模型骨架与挂点发生变化时，多SP外观可能回退或不适配。
• 同名dwmapi.dll、不同UE4SS版本、同时接管兵装或按键的Mod需要单独核对。F6可改键，避免与其他Mod冲突。
• 兼容记录是特定版本/场景的结果，不是对所有Mod的保证；本包未捆绑上述第三方Mod。
