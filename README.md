## 2.21.1更新说明

- 新增默认关闭的机炮齐射，Ctrl+Alt+F5可开关和改键；原生机枪联动MGP/PLSL，松开尝试恢复原选择。HGP及不同SP真正并发暂不支持，切槽可能有间隙。
- 按住Shift/Ctrl/Alt时可使用兵装直选等单键功能，完整组合快捷键优先；四个Mod快捷键均参与回中避让。
- F6为“基础、视角、日志、调试”；新配置的注视/镜头保持默认关闭，升级保留原设置和个人方案。
- 调试换机支持三SP数据完整的已加载Mod机体，可按名称/代号/编号搜索，按来源及首字母筛选，仍通过重开完整任务生效。
- 修补CFA旧炮口记录失配时的单次放行窗口；F-15 S/MTD的HPAA＋FAEB及三SP补为HPAA2/FAEB2。F-4E保持50%配弹和9枚显示。

已验收冻结构建`Temp/build-2.21.1-candidate`，原11项现有检查及安装回执保持。管理14/配置13/注视2/镜头5/换机2；配置12迁移前保存`profiles.before-gun-salvo.json`原字节，新齐射快捷键冲突时只把新键留空。发布仅将product的candidate从true改false，发布工具精确核对这一元数据差异，其余冻结源码/产物严格一致。

本地发布包`Release/AC7MultiSP-2.21.1.zip`：ReadMe开头概括当前变化，末尾列出2.0至2.21.1的38条简明日志；2.1.0/2.1.1写“中间测试版本”。原有适配表和必要备注保留。见[验收](evidence/2.21.1-user-validation.json)、[发布回执](evidence/2.21.1-release.json)、[整合](evidence/2.21.1-integration.json)及[实际安装](evidence/2.21.1-installed.json)。
