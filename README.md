## 2.21.1更新说明

- 新增默认关闭的机炮齐射，Ctrl+Alt+F5可开关和改键；原生机枪联动MGP/PLSL，松开尝试恢复原选择。HGP及不同SP真正并发暂不支持，切槽可能有间隙。
