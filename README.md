# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，分别保留弹药和装填，提供原生选装/HUD、中英文管理及部分机体的多SP模型。

唯一正式主线：**main / v2.21.0**。用户测试2.20.3后反馈“测试无误”，授权合main、统一2.21.0并制作本地发布包。2.21.0仅改版本标识后完整重建及检查；功能源码与已验收2.20.3一致，不扩大为全机体全组合、全部Mod兼容或固定性能达成。

## 2.21.1整合候选（待用户验收）

本次接收四线程最新成果：CFA `3ecdfd8`、键鼠/F6 `66e75f9`（含`effa304`）、机炮齐射`90891aa`（含`3f9badc`）、挂载`437665d`（含F-15修订`b708a22`）。键鼠来源的2.21.2标识统一为2.21.1；正式main及本地发布仍为2.21.0，验收前不合main、不制作发布包。

- 新配置的保持注视和镜头保持默认关闭；已有保存选择、键位、比例和机体方案保留。F6改为“基础、视角、日志、调试”，基础页集中武器与Mod快捷键。
- 按住Shift/Ctrl/Alt时可使用兵装直选等单键功能；完整配置组合优先，四个Mod快捷键均参与镜头回中避让，避免同一次按压触发两个功能。
- 调试换机支持实际加载目录中三SP数据完整的Mod机体，提供名称/代号/编号搜索、来源与首字母筛选；仍通过重开完整任务应用。
- 新增默认关闭的机炮齐射，Ctrl+Alt+F5可开关并自定义：MGP/PLSL联动原生机枪动作，松开尝试恢复原选择。HGP、多个不同SP真正并发暂不支持，切槽可能有发射间隙。
- CFA旧炮口组件记录失配时重新核对当前组件，避免单次误放行；不增加正常路径逐帧扫描，偶发双侧蓝光及性能仍待观察。
- F-15 S/MTD的HPAA＋FAEB及三SP补为HPAA2/FAEB2；54资源不变。F-4E按用户选择保持50%配弹和9枚显示，布局设计优先左右对称、支撑和净空，不以库存限制设计容量。

本候选已成套构建、通过11项现有检查并安装，18运行文件与54资源/108成员一致，个人配置/存档/其他Mod保留，游戏未自动启动。效果待用户实测。整合接口为管理14/配置13/注视2/镜头5/换机2。配置12升级前保存`profiles.before-gun-salvo.json`原字节；新齐射快捷键与旧键冲突时只把新键留空。旧冻结产物和回执不改。来源见[整合回执](evidence/2.21.1-integration.json)。

## 2.21.0更新说明（相对2.20.0，历史）

- 中央武器简称新增始终显示/切换后1秒；X原生轮切，L3松开保持注视，R3短按松开换视角、长按0.3秒回中，双摇杆只干扰弹。
- 新配置默认启用注视、镜头保持及R3回中；旧镜头保持选择、键位和方案保留，配置12迁移前逐级备份。F6为四页卡片、按需帮助和固定保存区。
- 持续注视同一目标时切换普通三视角接续方向及进度；准备页、兵装和挂架字段名持续持有，规避已定位的F-22准备页缓存崩溃，升级须完整退出游戏。

## 使用与交付

本分支另有 **2.21.1机炮齐射源码候选**：默认关闭，按住原生机枪动作联动方案内已核对的MGP或PLSL，松开恢复先前选择；管理开关及可改的Ctrl+Alt+F5已接入。用户只读协助采集MiG-21bis/Su-57原生依据，候选未编译、测试或安装；HGP及多种不同SP并发不支持。见[开发说明](docs/development.md#机炮齐射源码候选2211)和[设计边界](docs/architecture.md#机炮齐射源码候选2211未编译)。正式发布仍为2.21.0，本机已测/安装仍为2.20.3。
