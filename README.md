# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，分别保留弹药和装填，提供原生选装/HUD、中英文管理及部分机体的多SP模型。

唯一正式主线：**main / v2.20.0**。用户确认最新改动全部有效，授权合入main并制作本地发布包。2.20.0基于已验收2.19.5，仅统一版本标识后完整重建及检查，功能源码不变；本轮没有重装或启动游戏，旧候选、备份和2.19.0发布包保留。验收不扩大为全机体全组合或10ms目标达成。

## 当前2.20.2测试候选

`codex/integration-2.20.2`接收镜头线程`codex/tracking-view-continuity`的`03684fb`，基线为已安装2.20.1/`3ec3325`。镜头保持开启且持续注视同一目标时，普通第一人称、座舱和第三人称切换接续注视进度与方向，修订先回正再注视的问题。按键、默认值和协议13/配置12/注视2/镜头4不变。已成套编译、通过11项现有检查并安装，新效果待用户测试；正式main和发布包仍为2.20.0。

沿用2.20.1的中央简称显示选项、L3松开注视、R3短按松开换视角/长按0.3秒回中、双摇杆只干扰弹、F6四页管理及54资源/108成员挂载。此前用户确认手柄与管理页正常，不扩大为所有组合或性能验收。冻结构建`Temp/build-2.20.2-candidate`；来源记录见[注视衔接](evidence/tracking-view-continuity.json)，整合与实际安装见`evidence/2.20.2-integration.json`、`evidence/2.20.2-installed.json`。旧候选、来源工作区及验收回执保持。

取证启动已改进错误窗口文字、异常/退出现场、持续连接检查和采集失败提醒；桌面“AC7 崩溃取证启动”沿用原入口。异常探针已保存首次异常、完整内存和退出转储；仍不能保证每次闪退都留下根因。见[取证改进](evidence/crash-capture-hardening-2.20.2.json)。PW-Mk.I一次出击崩溃、再次成功的记录继续保留，未标记修复。

## 2.20.0更新说明（相对2.19.0）

- 增加镜头方向保持（默认关闭，第二个“按键”页）：手柄松杆、键鼠松开视点操作模式键、短按切目标和普通视角切换后保持方向；长按Y或持续注视从当前方向转向目标，结束后返回保持方向。仅总功能启用时屏蔽原生自动回正。
- 独立回正默认鼠标中键，可自定义。右摇杆灵敏度5%～200%、默认100%；R3替换默认关闭，开启后短按松开回正，长按0.5秒立即换一次视角，双摇杆仍可释放干扰弹并回正。
- CFA-44双/三SP互切保留开合进度，减少炮口、模型及锁定/持续效果检查中的重复工作，降低切换停顿；首次加载仍可能较慢，不承诺固定10ms或完全无卡。
- 修订共用兵装重建前的旧锁定目标登记收尾，避免残留引发MSL/EML多发；保留正常多目标齐射。用户已确认最新改动有效，不扩大为全机体全组合验收。
- ADF-01 TLS及尾迹期间丢弃切换请求，结束后需要重新按键，不提前停光、不排队自动切换。
- 取消手柄X正常目标注视开关弹窗，保留错误、无目标及键盘提示。旧个人设置保留，必要的配置迁移会先备份。
