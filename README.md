# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，并保留各自弹药、装填和切换。提供原生选装、HUD、部分机体的多SP外观及中英文管理界面。

当前主线及发布版：**2.19.0**。用户已确认CFA-44切换修订有效、卡顿明显减少，并授权合入。第13关限制、按键页注视设置及CFA任务外原生模型策略沿用。本地发布包已生成并完整核验，沿用已测字节，没有重新构建或安装。任务结算界面箭头卡顿已明显缓解，仍有轻微卡顿，作为已知问题保留。

用户反馈不扩大为完全无卡或全机全组合验收，其他待办继续保留。同类小优化仅递增补丁号。当前整合候选 **2.19.5** 位于`codex/integration-2.19.5`，基于已安装2.19.4，仅接收镜头线程`9ee1883`：普通视角切换接续观察方向，长按Y从当前方向直接转向目标，取消手柄X正常注视开关弹窗。已成套构建、通过11项现有检查并安装；17运行文件、50资源/100成员PAK一致，23项保护文件、完整备份及存档备份核验通过；正式main及发布包仍为2.19.0。

CFA继续减少持续效果、锁定收尾、数组及炮口只读检查中的重复查询，保留原生解除锁定、停音和引擎边界复核。计时修订4区分本轮样本。用户已确认2.19.3优化有效，非首次43次切换中位26.12ms，双发暂未复现，首次峰值可接受；这些不作为当前候选成绩，10ms仍为未验证目标。依据及有效/无效经验见[实测](evidence/cfa44-2.19.3-switch-observation.json)、[评估](evidence/cfa44-10ms-assessment.json)及[设计经验](docs/multi-sp-mount-design.md#已验证经验与踩坑)。

镜头输入修订把右摇杆灵敏度改为5%～200%、默认100%，新增默认关闭的R3替换开关。开启该开关才执行短按释放回正、长按0.5秒立即换视角；关闭时R3走原生。补齐键鼠松开视点操作模式键、短按切目标后的方向保持，真正注视仍优先；独立回正默认中键。镜头总功能仍默认关闭，子设置仅开启时显示和生效。协议11/配置10/镜头子协议3成套部署，首次启动先备份旧配置，再补R3默认关闭，旧灵敏度高于200时限为200，其余有效设置保留。用户反馈已安装镜头各项功能正常，另指出换视角和长按Y开始注视时仍先回正。本轮源码接续普通视角间的观察方向，保留注视过渡的环视起点；所有回正屏蔽仅在camera-hold开启时生效，并取消手柄X正常切换注视的开关弹窗。此次修订已接收至2.19.5，按授权成套构建安装，实际效果待用户测试，见[衔接修订](evidence/camera-view-continuity.json)；[旧输入来源](evidence/camera-input-coverage.json)保留。

FALKEN发射及尾迹期间忽略切换请求、结束后重新按键的策略沿用。交付回执见[证据索引](evidence/README.md)。
