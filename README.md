# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，并保留各自弹药、装填和切换。提供原生选装、HUD、部分机体的多SP外观及中英文管理界面。

当前主线及发布版：**2.19.0**。用户已确认CFA-44切换修订有效、卡顿明显减少，并授权合入。第13关限制、按键页注视设置及CFA任务外原生模型策略沿用。本地发布包已生成并完整核验，沿用已测字节，没有重新构建或安装。任务结算界面箭头卡顿已明显缓解，仍有轻微卡顿，作为已知问题保留。

用户反馈不扩大为完全无卡或全机全组合验收，其他待办继续保留。后续同类小优化递增补丁号，当前候选为2.19.2。当前实现和验证边界见[挂载设计](docs/multi-sp-mount-design.md)。

当前整合候选 **2.19.2** 位于`codex/integration-2.19.2`，从已安装2.19.1接收CFA发射切换边界和减负、FALKEN发射期间丢弃切换请求，以及R3短按漏放原生换视角回调的修订。候选已成套构建、通过现有安装所需检查并安装，双发是否消失、性能改善和R3效果待用户实测；正式main及发布包仍为2.19.0。

2.19.1反馈继续保留：CFA互切已不重复展开，但仍明显卡顿；发射ADMM后切回MSL概率双发扣2，关闭模型时也报告EML双发；镜头保持基本正常，但R3短按会兼触换视角。原研究、修订依据和验收边界保留于[证据索引](evidence/README.md)。

2.19.2现场复现确认CFA的MSL/EML仍双发：重建丢弃旧锁定槽，却留下旧目标登记。后续源码在所有机体共用重建入口补齐原生解除锁定，未构建安装。已安装2.19.2的三SP模型开启切换中位数41.18ms（103次），较旧83.43ms约减半，但仍会短卡，首次716.48ms峰值也仍存在。现场及修订见[双发根因与计时](evidence/cfa44-live-seeker-residue.json)。

用户追加约20ms目标后，源码继续合并短只读块的重复查页，保留身份判断及引擎调用前后的独立检查；新计时会记录实际查页和复用量。尚未编译实测，20ms不是已经达到的成绩，见[优化依据](evidence/cfa44-read-batch-optimization.json)。
