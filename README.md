# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，分别保留弹药和装填，提供原生选装/HUD、中英文管理及部分机体的多SP模型。

唯一正式主线：**main / v2.21.0**。用户测试2.20.3后反馈“测试无误”，授权合main、统一2.21.0并制作本地发布包。2.21.0仅改版本标识后完整重建及检查；功能源码与已验收2.20.3一致，不扩大为全机体全组合、全部Mod兼容或固定性能达成。

## 2.21.0更新说明（相对2.20.0）

- 中央武器简称新增始终显示/切换后1秒；X原生轮切，L3松开保持注视，R3短按松开换视角、长按0.3秒回中，双摇杆只干扰弹。
- 新配置默认启用注视、镜头保持及R3回中；旧镜头保持选择、键位和方案保留，配置12迁移前逐级备份。F6为四页卡片、按需帮助和固定保存区。
- 持续注视同一目标时切换普通三视角接续方向及进度；准备页、兵装和挂架字段名持续持有，规避已定位的F-22准备页缓存崩溃，升级须完整退出游戏。
- XFA-27补齐SOD＋MSTM的两处MSTM并保留支架；MiG-35D双挂成对，完整54资源/108成员须与核心/Lua成套。

本地包`Release/AC7MultiSP-2.21.0.zip`包含中英文说明、适配表、Mod、挂载包、专用加载器和微软运行库。实测与本机安装仍记为2.20.3，实际安装基线为`evidence/2.20.3-installed.json`；2.21.0发布清单不冒充新实机验收。见[验收](evidence/2.21.0-user-validation.json)、[发布](evidence/2.21.0-release.json)及[版本标识证明](evidence/2.21.0-version-label-build.json)。

本机取证启动已增强消息框、异常/退出现场、连接与产物检查；属于项目诊断工具，未捆入游戏包。PW曾一次出击崩溃、再次成功，原因待查；不借F-22修订推定同因。旧构建、原始现场及回执保留。
