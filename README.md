# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，并保留各自弹药、装填和切换。提供原生选装、HUD、部分机体的多SP外观及中英文管理界面。

当前主线及发布版：**2.19.0**。用户已确认CFA-44切换修订有效、卡顿明显减少，并授权合入。第13关限制、按键页注视设置及CFA任务外原生模型策略沿用。本地发布包已生成并完整核验，沿用已测字节，没有重新构建或安装。任务结算界面箭头卡顿已明显缓解，仍有轻微卡顿，作为已知问题保留。

用户反馈不扩大为完全无卡或全机全组合验收，其他待办继续保留。后续同类小优化仅递增补丁号，当前整合候选 **2.19.3** 位于`codex/integration-2.19.3`。本轮从已安装2.19.2接收两线程最新提交，已成套构建、通过11项现有检查并安装；17运行文件、50资源/100成员PAK一致，195项保护文件、完整备份及存档备份核验通过；正式main及发布包仍为2.19.0。

CFA双发修订`99fc952`在所有机体共用的兵装重建入口补齐原生解除锁定；`4b5c1b5`合并短只读过程的重复查页。2.19.3三SP开启模型44次切换中位数26.19ms，排除首次后的43次为26.12ms，较2.19.2的41.18ms继续改善；用户确认优化有效、双发目前未复现，并接受首次峰值。详见[最新实测](evidence/cfa44-2.19.3-switch-observation.json)。

已将有效手段、有限/失败尝试及跨机体复用边界整理进[设计经验](docs/multi-sp-mount-design.md#已验证经验与踩坑)。独立研究分支`codex/cfa44-10ms`继续减少锁定/持续效果等短只读路径的重复查询，保留原生收尾；仅源码和文档，未编译测试安装，10ms没有实测保证，见[评估](evidence/cfa44-10ms-assessment.json)。

镜头控制扩展`c3102d4`：R3满0.5秒无需松开即换视角，短按松开回正；独立回正键默认鼠标中键，右摇杆灵敏度25%～300%、默认100%。子设置仅镜头保持开启时展示和生效。管理协议10、配置9，首次启动先备份旧配置再补入新设置，保留既有开关、注视、键位和方案。用户对2.19.2短按修订的正常反馈保留，不扩大为新扩展验收，见[来源说明](evidence/camera-controls-options.json)。

FALKEN发射及尾迹期间忽略切换请求、结束后重新按键的策略沿用；CFA互切无重复展开已获反馈，但仍有短卡。交付回执见[证据索引](evidence/README.md)，实现边界见[挂载设计](docs/multi-sp-mount-design.md)。
