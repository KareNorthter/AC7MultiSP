# DualSP 0.1.7

项目总入口：[AGENTS.md](AGENTS.md)。这是 Steam AC7 的双特殊兵装模组：保留普通导弹，任务中循环使用 SP1、SP2，分别保存弹药和冷却。

## 使用

当前模组已安装在本机游戏中。正常进入机库，选择机体，再进入原来的特殊兵装页：

1. 选择 SP1，再选择 SP2；SP2 可以选“无兵装”。
2. 进入确认页，松开按键后，再按一次原生决定键继续。
3. 出击后使用原游戏切换键循环 **MSL → SP1 → SP2 → MSL**；耗尽的 SP 会跳过。F9 是额外循环键。

原生准备页目前支持键盘和手柄，决定/返回读取游戏映射。详细操作见[原生选择页](docs/native-loadout.md)。**F8** 保留原有鼠标、键盘与手柄配置窗口，其“界面设置”可以关闭原生准备选择。配置按机体保存，出击后锁定；任务中打开 F8 会暂停游戏。

双 SP 默认各使用原载弹量的 50%，F8 可调整比例；这是模组规则，不能视为已经确认的 AC8 精确比例。SP2 为空时 SP1 保留完整载弹量。准备页显示基础配弹预计数，强化部件影响以任务内实际数值为准。

## 安装与恢复

本机仅支持已核对的 Steam build **9855922**。可使用[当前安装包](Release/DualSP-0.1.7.zip)，或在退出游戏后运行根目录 `Install.cmd`；安装程序校验游戏和专用加载器，备份原模组并保留配置。卸载入口为 `Uninstall.cmd`，不会直接删除配置。

日志与配置位于游戏目录 `ue4ss/Mods/DualSP/`：`mod.log`、`native.log`、`profiles.json`。兵装错误会停止武器修改；HUD/准备页接入错误会明确显示，F8 可查看原因。开发目录迁移不会修改已安装模组或存档。

## 当前边界

- 用户已确认 0.1.5 的切换、发射和 HUD 排版正常；0.1.6 闪烁修复、0.1.7 原生准备页仍待实玩确认。
- 原生准备页比 AC8 多一次确认；鼠标点选、说明视频、挂载预览联动暂未接入，鼠标操作可使用 F8。
- 检查点、自然补给及部分特殊武器的完整覆盖仍属实验性。UAV/ECM 不支持双挂。
- 当前飞机只显示正在激活的 SP 挂载。双模型目标[暂缓保留](docs/research/weapon-models.md)。
- 单机战役和自由任务是目标范围；VR、多人、第三方新增机体及其他武器修改未作兼容保证。52 行原生机体数据的支持不等于全部机体实测通过。

已有验证及其边界见[证据目录](evidence/README.md)，实现结构见[架构说明](docs/architecture.md)。本轮仅整理资产、文档与 Git，未编译或运行测试。
