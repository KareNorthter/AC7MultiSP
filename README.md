# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，并保留各自弹药、装填和切换。提供原生选装、HUD、部分机体的多SP外观及中英文管理界面。

当前主线及发布版：**2.19.0**。用户已确认CFA-44切换修订有效、卡顿明显减少，并授权合入。第13关限制、按键页注视设置及CFA任务外原生模型策略沿用。本地发布包已生成并完整核验，沿用已测字节，没有重新构建或安装。任务结算界面箭头卡顿已明显缓解，仍有轻微卡顿，作为已知问题保留。

用户反馈不扩大为完全无卡或全机全组合验收，其他待办继续保留。后续同类小优化仅递增补丁号，当前整合候选 **2.19.3** 位于`codex/integration-2.19.3`。本轮从已安装2.19.2接收两线程最新提交，已成套构建、通过11项现有检查并安装；17运行文件、50资源/100成员PAK一致，195项保护文件、完整备份及存档备份核验通过；正式main及发布包仍为2.19.0。

CFA双发修订`99fc952`在所有机体共用的兵装重建入口补齐原生解除锁定；`4b5c1b5`合并短只读过程的重复查页，保留身份判断及引擎调用前后的独立检查。2.19.2现场仍复现MSL/EML双发，模型开启103次切换中位数41.18ms，首次峰值716.48ms；这些是旧安装版数据。新修订是否消除双发、是否接近20ms均待用户实测。依据见[现场证据](evidence/cfa44-live-seeker-residue.json)及[优化记录](evidence/cfa44-read-batch-optimization.json)。

已安装镜头扩展`c3102d4`的协议10/配置9回执保留。后续[镜头输入修订](evidence/camera-input-coverage.json)仅改源码：灵敏度5%～200%默认100%，新增默认关闭的R3替换开关，并处理松开键鼠视点模式键及短按切目标时的自动回正。仅camera-hold启用时提供子功能；新源码协议11/配置10/镜头子协议3。三段只读采样观察旧安装，新修订未编译安装，待实测。

FALKEN发射及尾迹期间忽略切换请求、结束后重新按键的策略沿用；CFA互切无重复展开已获反馈，但仍有短卡。交付回执见[证据索引](evidence/README.md)，实现边界见[挂载设计](docs/multi-sp-mount-design.md)。
