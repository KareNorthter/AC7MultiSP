# AC7MultiSP

在《皇牌空战7》单人任务中选择1至3种特殊兵装，并保留各自弹药、装填和切换。提供原生选装、HUD、部分机体的多SP外观及中英文管理界面。

当前主线：**main / 2.19.0**。用户已确认CFA-44切换修订有效、卡顿明显减少，并授权合入。第13关限制、按键页注视设置及CFA任务外原生模型策略沿用。本轮沿用已测2.19字节制作本地发布包，不重新构建或安装。任务结算界面箭头卡顿已明显缓解，仍有轻微卡顿，作为已知问题保留。

用户反馈不扩大为完全无卡或全机全组合验收，其他待办继续保留。后续同类小优化递增补丁号，下一版为2.19.1。当前实现和验证边界见[挂载设计](docs/multi-sp-mount-design.md)。
